# Glass Roulette 🎲📹

Анонимная видео-чат-рулетка в фирменном стиле **Liquid Glass**: случайные собеседники по всему миру, видео + звук + зашифрованный чат. Android 5.0+ (API 21+).

## Возможности

- 🎥 **Видео + звук P2P** через WebRTC — поток идёт напрямую между телефонами.
- 💬 **Текстовый чат** прямо во время звонка (WebRTC DataChannel).
- 🔒 **Сквозное шифрование чата**: ECDH P-256 (обмен ключами) + SHA-256 + **AES-256-GCM**. Ключи создаются заново для каждого звонка и не покидают устройства — даже сервер прочитать сообщения не может. Поверх этого сам канал шифруется DTLS.
- 🌍 **Фильтр по стране**, языку и полу.
- 🏷️ **Интересы** — подбор в первую очередь по общим темам.
- 🌫️ **Блюр своей камеры** — программный box-blur кадров в реальном времени (можно включить по умолчанию).
- 🚫 **Чёрный список**: заблокированный человек больше никогда не попадётся. Список хранится зашифрованным (AES-256, ключ в AndroidKeyStore).
- 🚨 **Жалобы** с причинами — уходят в Firestore (читать их может только владелец проекта в консоли).
- ⏭️ **Далее / Стоп**, автопереход по таймеру (15/30/60 c), автоподбор нового собеседника, если текущий вышел.
- 🎤 **Микрофон**, 📷 **камера**, 🔄 **смена камеры**, 🔊 **динамик**, 🌫️ **блюр** — всё переключается на лету.
- ❤️ Реакции-эмодзи, лайки, индикатор «печатает…», счётчик непрочитанных.
- 📶 **Индикатор качества связи** (по RTT из WebRTC-статистики) и таймер разговора.
- 👥 **Счётчик онлайна**.
- 🔞 Возрастной экран 18+ и правила при первом запуске.
- 🎨 Liquid Glass: 7 акцентов + системный (Material You), тёмная/светлая тема, слайдеры размытия/непрозрачности/скругления/шрифта/блика, RU/EN.
- 🛡️ **Защита приложения**: R8 full mode (обфускация + вырезание кода и ресурсов), удаление логов, `allowBackup=false`, приватное хранилище, опциональный запрет скриншотов (FLAG_SECURE).

## Как это работает

```
 Телефон A                Firestore                 Телефон B
     │  queue/{uid} (публичный ключ ECDH)  │              │
     │────────────────────────────────────▶│              │
     │            rooms/{id}: offer ◀──────│── подбор ────│
     │  ICE кандидаты ◀─── callerIce/calleeIce ─────▶     │
     │                                                    │
     │◀═════════════  WebRTC P2P (DTLS)  ═════════════════▶│
     │        видео + звук + DataChannel (AES-256-GCM)     │
```

- **Firestore** используется только как «доска объявлений» для знакомства (offer/answer/ICE) и счётчика онлайна. Сообщения и медиа через него **не идут**.
- **Сервер не нужен**: STUN — публичные Google, TURN (для жёстких мобильных NAT) — бесплатный публичный Open Relay. На части мобильных сетей (~10–20% пар) соединение может не установиться — это ограничение любой рулетки без собственного TURN.
- «Сервера посередине» для видео нет вообще: поток идёт напрямую между телефонами.

## Настройка Firebase (один раз)

1. [console.firebase.google.com](https://console.firebase.google.com) → проект → включить **Authentication → Anonymous** и **Firestore Database**.
2. Firestore → Правила → вставить содержимое [`firestore.rules`](firestore.rules) → Опубликовать.
3. `app/google-services.json` уже на месте.

## Сборка

```bash
cd chat-roulette
gradle assembleRelease   # APK: app/build/outputs/apk/release/app-release.apk
```

CI (`.github/workflows/chat-roulette.yml`) сам собирает релиз, прогоняет смоук-тест на эмуляторах API 24 и 34 и публикует APK в GitHub Releases.
