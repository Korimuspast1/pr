# МКАД Райдер — 3D мотогонки

3D-игра на JavaScript + Three.js: едешь на спортбайке по МКАДу — 5 полос в свою сторону,
бетонное ограждение по центру, попутный трафик (седаны, хэтчи, фургоны, фуры),
путепроводы, зелёные вывески съездов, километровые столбики и лес по обочинам.

## Запуск

Это чистая статика — любой веб-сервер:

```bash
cd mkad-rider
python3 -m http.server 8000
# открыть http://localhost:8000
```

Или просто открыть `index.html` через локальный сервер (не через `file://` — ES-модули).

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `↑` | газ |
| `S` / `↓` / `Пробел` | тормоз |
| `A` / `D` (`←` `→`) | руль — байк заваливается в наклон и прописывает дугу |
| `Shift` | **вилли — встать на заднее колесо** |
| `Мышь` | **обзор**: клик по дороге захватывает курсор (`Esc` — отпустить). Без захвата — зажми и веди |
| `C` | камера: погоня / близкая / шлем |
| `M` | звук вкл/выкл |
| `P` / `Esc` | пауза |
| `R` | начать заново |

На телефоне — экранные кнопки (вилли — кнопка «ВИЛЛИ»). Цвет мотоцикла выбирается на стартовом экране.

## Повороты — как на настоящем мотоцикле

Руль задаёт не сдвиг вбок, а наклон: байк сначала заваливается корпусом (до ~35°),
и уже из наклона рождается боковая сила — дуга прописывается за корпусом, нос
доворачивается за траекторией. Никакого «скольжения» — заходи в поворот заранее.

## Станты

Держи `Shift` — байк резко встаёт на заднее колесо (подхват ~0.4 с), банк станта
копится каждую секунду. Отпустил и приземлился аккуратно — банк переходит в очки,
вилка сжимается от удара, камера «клюёт». Перевернулся — крэш.

Физика честная, как на настоящем мотоцикле:

- с газом байк стабильно держит баланс около 60° — газуй смелее;
- **без газа или на малой скорости задирает на спину** — вовремя отпусти или добавь газ;
- на скорости ниже ~50 км/ч вилли неустойчив: нет гироскопа — держи обороты;
- руль на заднем колесе почти не слушается (×0.35) — закони вилли заранее.

## Подвеска и дорога

Колёса реально касаются покрытия: микропрофиль асфальта раскачивает подвеску,
переезд стыка между полосами даёт «тук» и толчок в вилку, у отбойника начинается
гравийная тряска. Разгон прижимает зад, тормоз грузит перед — байк приседает и клюёт носом.

## Приборная панель

ЖК-приборка спортбайка на HTML canvas: спидометр до 299 км/ч, тахометр с красной
зоной, повышенная передача, температура, топливо, пробег, индикаторы СТАНТ и ЗАДАЧА
(близкий проезд). В шлем-камере приборка уменьшается и уезжает в левый угол — не мешает взгляду.

## Камеры

- **Погоня** — классическая камера за байком с пружинной подвеской;
- **Близкая** — ниже и ближе, «как в зеркале»;
- **Шлем-камера** — камера в голове мотоциклиста: наклоняется с байком в поворотах,
  микротряска на неровностях, виден капот приборки и руки.

Во всех камерах работает **обзор мышью**: клик — захват курсора, мышь вертит камеру
(в шлеме — голову райдера). Отпустил курсор — взгляд плавно возвращается вперёд.

## Звук

Двигатель — синтез рядной «четвёрки» (600 кубов): рык внизу, визг на верхах,
«пердёж» глушителем на сбросе газа, отсечка на максималке, впуск, ветер и гул шин.
Переключение передач — с клацем и провалом газа, посадка с вилли — удар подвески,
стыки покрытия — глухие туки.

## Номера

Европейский формат: синяя полоса ЕС с кольцом звёзд и кодом RUS, белый фон,
чёрные знаки. У каждой машины свой случайный номер (формат РФ: Б ЦЦЦ ББ РР),
на байке — свой номер сзади.

## Файлы

- `index.html` — разметка, HUD, оверлеи
- `main.js` — игровой цикл, физика (fixed timestep 120 Гц), трафик, камеры, приборка
- `bike.js` — процедурная модель спортбайка + мотоциклист (~120 деталей)
- `cars.js` — седаны, хэтчбеки, фургоны, фуры (с еврономерами)
- `world.js` — дорога, небо, свет, ограждения, фонари, деревья, путепроводы, вывески
- `textures.js` — процедурные текстуры (асфальт с разметкой и колеями, трава, бетон, вывески, номера)
- `audio.js` — синтез звука рядной четвёрки (WebAudio)
- `bake.js` — слияние статичной геометрии (оптимизация draw calls)
- `three.module.min.js` — Three.js r160 (MIT)

## Особенности

- **Производительность**: статичные детали мотоцикла, машин и декораций сливаются
  в меш-пакеты по материалам — draw calls втрое меньше; деревья и фонари рисуются
  инстансами с инкрементальным рециклингом (без аллокаций и фризов)
- Физика с фиксированным шагом 120 Гц — плавно на любой частоте кадров
- Пул машин: трафик переиспользует модели без сборки мусора
- Все модели построены из скруглённой геометрии (капсулы, торы, экструзии с фасками) — без «кубиков»
- Текстуры генерируются на лету: асфальт с шумом, трещинами, колеями и ГОСТ-разметкой, карты шероховатости и нормалей
- Трафик с перестроениями и «поворотниками», бонус за близкий проезд («вжух!»)
- Причины крэшей на русском: столкновение, отбойник, «лег спиной», переворот на вилли
- Рекорд сохраняется в localStorage, адаптивное качество рендера (ретина → тени)
