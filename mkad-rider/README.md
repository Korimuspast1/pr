# МКАД Райдер — 3D мотогонки

3D-игра на JavaScript + Three.js: едешь на спортбайке по МКАДу — 5 полос в свою сторону,
бетонное ограждение по центру, попутный трафик (седаны, хэтчи, фургоны, фуры),
путепроводы, зелёные вывески съездов, километровые столбики и лес по обочинам.

## Запуск

Это чистая статика — любой веб-сервер:

```bash
cd mkad-rider
python3 -m http.server 8000
# открыть http://localhost:8000
```

Или просто открыть `index.html` через локальный сервер (не через `file://` — ES-модули).

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `↑` | газ |
| `S` / `↓` / `Пробел` | тормоз |
| `A` / `D` (`←` `→`) | руль (наклон в поворот) |
| `Shift` | **вилли — встать на заднее колесо** |
| `C` | камера: погоня / близкая / **шлем-камера** |
| `M` | звук вкл/выкл |
| `P` / `Esc` | пауза |
| `R` | начать заново |

На телефоне — экранные кнопки (вилли — кнопка «ВИЛЛИ»). Цвет мотоцикла выбирается на стартовом экране.

## Станты

Держи `Shift` — байк встаёт на заднее колесо, а банк станта копится каждую секунду.
Отпустил и приземлился аккуратно — банк переходит в очки. Перевернулся — крэш.

Физика честная, как на настоящем мотоцикле:

- с газом байк стабильно держит баланс около 60° — газуй смелее;
- **без газа или на малой скорости задирает на спину** — вовремя отпусти или добавь газ;
- на скорости ниже ~50 км/ч вилли неустойчив: нет гироскопа — держи обороты;
- руль на заднем колесе почти не слушается (×0.35) — закони вилли заранее.

## Приборная панель

ЖК-приборка спортбайка на HTML canvas: спидометр до 299 км/ч, тахометр с красной
зоной, повышенная передача, температура, топливо, пробег, индикаторы СТАНТ и ЗАДАЧА
(близкий проезд). Стрелки с плавным ходом, ночью ничего не слепит.

## Камеры

- **Погоня** — классическая камера за байком с пружинной подвеской;
- **Близкая** — ниже и ближе, «как в зеркале»;
- **Шлем-камера** — камера в голове мотоциклиста: наклоняется с байком в поворотах,
  микротряска на неровностях, виден капот приборки и руки. `C` переключает.

## Файлы

- `index.html` — разметка, HUD, оверлеи
- `main.js` — игровой цикл, физика (fixed timestep 120 Гц), трафик, камеры, приборка
- `bike.js` — процедурная модель спортбайка + мотоциклист (~120 деталей)
- `cars.js` — седаны, хэтчбеки, фургоны, фуры
- `world.js` — дорога, небо, свет, ограждения, фонари, деревья, путепроводы, вывески
- `textures.js` — процедурные текстуры (асфальт с разметкой и колеями, трава, бетон, вывески)
- `audio.js` — синтез звука двигателя и ветра (WebAudio)
- `three.module.min.js` — Three.js r160 (MIT)

## Особенности

- Физика с фиксированным шагом 120 Гц — плавно на любой частоте кадров
- Все модели построены из скруглённой геометрии (капсулы, торы, экструзии с фасками) — без «кубиков»
- Текстуры генерируются на лету: асфальт с шумом, трещинами, колеями и ГОСТ-разметкой, карты шероховатости и нормалей
- Трафик с перестроениями и «поворотниками», бонус за близкий проезд («вжух!»)
- Причины крэшей на русском: столкновение, отбойник, «лег спиной», переворот на вилли
- Рекорд сохраняется в localStorage, адаптивное качество рендера
