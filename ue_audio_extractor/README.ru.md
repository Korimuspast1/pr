# UE Audio Extractor

Небольшая офлайн-утилита для поиска аудио в **распакованных** ресурсах Unreal Engine и сохранения потоков в отдельные файлы. Исходники не меняются. Есть окно и CLI, внешние Python-пакеты не нужны.

> **Важно:** `.uasset/.uexp` — сериализованные пакеты, а не универсальные аудиофайлы. Формат зависит от версии UE и выбранного при сборке кодека. Эта версия находит потоки с проверяемыми стандартными сигнатурами; она не является полным парсером всех Unreal-кодеков и не снимает шифрование.

## Запуск

### Windows — запуск в один щелчок

Установите Python 3.10+ с включённым Tkinter и дважды щёлкните `UE Audio Extractor.pyw` в корне репозитория. Откроется окно — выберите один файл кнопкой **Выбрать файл…** или целую папку кнопкой **Выбрать папку…**, затем укажите папку результата и нажмите **Найти и извлечь**. Для папки утилита проверит вложенные каталоги.

Если нужен самостоятельный `.exe`, один раз запустите `build_windows_exe.bat` в этой папке. Скрипт соберёт `dist/UE-Audio-Extractor-windows-x64.exe` (для сборки нужны Python и интернет; после сборки Python для запуска `.exe` не нужен). FFmpeg по-прежнему потребуется только для перекодирования в другой формат.

### CLI (Windows, macOS, Linux)

Из корня репозитория:

```bash
# Окно
python -m ue_audio_extractor

# Сохранить найденное в исходном формате — рекомендуется
python -m ue_audio_extractor -i "/game/Content" -o "./Music"

# Конвертировать в MP3
python -m ue_audio_extractor -i "/game/Content" -o "./Music" --format mp3

# Просканировать и файлы с незнакомыми расширениями (медленнее)
python -m ue_audio_extractor -i "/game/Content" -o "./Music" --scan-all --format flac
```

Форматы `--format`: `original` (по умолчанию), `mp3`, `flac`, `wav`, `ogg`. Для перекодирования нужен **FFmpeg** в `PATH` или укажите его явно через `--ffmpeg /путь/к/ffmpeg`. Для некоторых игровых аудиоформатов пригодится **vgmstream-cli** (`--vgmstream /путь/к/vgmstream-cli`). Если декодер установлен, он ищется автоматически.

## Что ищет

- отдельные аудиофайлы и банки: WAV, Ogg/Opus, MP3, FLAC, WEM, BNK, FSB и другие распространённые расширения;
- встроенные самодостаточные потоки в `.uasset`, `.uexp`, `.ubulk`, `.umap`, а также в некоторых `.pak/.ucas` и файлах с `--scan-all`: RIFF/WAVE (включая некоторые WEM), Ogg Vorbis/Opus, MP3, AIFF, CAF и аудио ISO-BMFF/M4A.

Соседние `.uasset`, `.uexp` и `.ubulk` сканируются как отдельные файлы. Найденные фрагменты получают имя вида `Asset.uexp.audio_001.ogg`. Одинаковые фрагменты пропускаются; существующие файлы результата не перезаписываются.

## Что эта версия не может извлечь автоматически

- зашифрованные `.pak` и IoStore-контейнеры `.utoc/.ucas`;
- данные, сжатые внутри контейнера, если до сигнатур не добраться обычным сканированием;
- сырые UE payload-ы без заголовка — например, часть PCM/ADPCM, XMA, Bink Audio или платформенных кодеков;
- один аудиопоток, разнесённый между файлами или описанный только бинарной сериализацией конкретной версии UE.

В таких случаях сначала распакуйте/экспортируйте ресурс подходящим для игры инструментом (например, FModel или UnrealPak, если у вас есть законный доступ к файлам), а затем просканируйте полученные файлы здесь. `vgmstream-cli` декодирует поддерживаемый **извлечённый** игровой аудиоформат, но сам по себе не разбирает все Unreal-пакеты.

## Какой формат выбрать

- **Исходный формат** — лучший выбор для сохранения качества и экономии места: поток просто копируется без повторного кодирования.
- **FLAC** — удобен для архива и не добавляет потерь при кодировании результата, но не восстанавливает качество, уже потерянное в исходном сжатом аудио.
- **WAV** — несжатый PCM, занимает много места; при конвертации записывается 24-битный WAV.
- **MP3** — наиболее совместимый вариант, но это формат с потерями. Подходит, если важна совместимость, а не архивное качество.
- **OGG** — перекодирование в Vorbis.

## Проверка и тесты

Зависимости для тестов не нужны:

```bash
python -m unittest discover -s ue_audio_extractor/tests -v
```

Утилита работает локально и не отправляет файлы в сеть. Используйте её только с ресурсами, к которым у вас есть право доступа.
