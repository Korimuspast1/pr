# 🏴 бот бандит — telegram-клон

Криминальная текстовая игра для Telegram, воссоздающая механики легендарного
ВК-бота **«бот бандит»** (vk.com/botbandit): такси, скам-рефералка, бизнесы,
казино, шмот, банды, трейды в стиле cs и жирная экономика с бедной стартовой
копейкой.

> ⚠️ Честное предупреждение. Оригинал — закрытый проприетарный проект:
> исходников, артов и точных чисел ни у кого нет. Это **ремейк по мотивам**:
> механики и вайб (весь текст — строчными, улица, `$250.000`) воссозданы,
> но баланс, названия машин/бизнесов и цены подобраны заново. 1 в 1 — только
> ощущения. 😌

## запуск в термуксе (android) — 5 минут

### 1. устанавливаем термукс
Скачай **Termux** с [F-Droid](https://f-droid.org/packages/com.termux/)
(версия из play market устарела) и открой его.

### 2. ставим python и зависимости
```bash
pkg update && pkg upgrade -y
pkg install python git -y
```

### 3. качаем бота
```bash
git clone <этот репозиторий>
cd <репозиторий>/bandit-bot
pip install -r requirements.txt
```
Если репозиторий приватный — просто скопируй папку `bandit-bot` в память
телефона любым способом (ftp/syncthing/otg).

### 4. получаем токен у @botfather
1. Открой телеграм → найди **@BotFather** → `/start`
2. Отправь `/newbot`
3. Придумай имя (например `Бот Бандит`) и username (например `moy_bandit_bot`,
   обязательно оканчивается на `bot`)
4. BotFather пришлёт токен вида `1234567890:AAE...` — скопируй его

### 5. кладём токен в файл и запускаем
```bash
echo 'СЮДА_ТВОЙ_ТОКЕН' > token.txt
chmod +x start.sh
./start.sh
```
Увидишь `@твой_бот запущен. «бот бандит» ждёт игроков…` — всё, бот живой.
Напиши ему в телеграме что угодно — игра начнётся.

> Токен можно также передать переменной: `BANDIT_TOKEN='...' ./start.sh`
> (тогда `token.txt` не нужен). **Никому не свети токен** — это полный доступ
> к боту. Файл `token.txt` в git не попадает.

### 6. чтобы работал в группах
По умолчанию бот в группах видит только команды с `/`. Чтобы он
реагировал на команды вроде `профиль` и `в путь`:
1. @BotFather → `/setprivacy` → выбери своего бота → **Disable**
2. Добавь бота в группу (или попроси админа добавить/выключить privacy там)
3. Всё. В группе он отвечает на те же команды, что и в личке, и не спамит
   лишним.

### 7. автозапуск при включении телефона (по желанию)
```bash
pkg install termux-boot -y
mkdir -p ~/.termux/boot
cat > ~/.termux/boot/bandit.sh <<'EOF'
#!/data/data/com.termux/files/usr/bin/bash
termux-wake-lock
cd ~/<репозиторий>/bandit-bot && ./start.sh
EOF
chmod +x ~/.termux/boot/bandit.sh
```
(папка должна называться точно репозиторий → `bandit-bot`)

### держать бота живым
- `termux-wake-lock` — не даёт android убивать процесс
- не закрывай термукс свайпом из последних приложений
- логи — прямо в консоли; Ctrl+C — остановка

## если что-то падает (термукс)

| симптом | что делать |
|---|---|
| `ModuleNotFoundError: telebot` | запусти `./start.sh` ещё раз — он сам всё поставит; либо `python -m pip install pyTelegramBotAPI` |
| `name 'is_admin' is not defined` (и такие же «is not defined») | у тебя старые файлы: `git pull && rm -rf __pycache__ && ./start.sh` |
| `❌ не могу достучаться до телеграма` | интернет на телефоне / токен (`@botfather` → `/token`) / vpn / нет интернета в термуксе |
| `Conflict: terminated by other getUpdates request` | бот запущен в двух местах сразу — закрой лишний экземпляр |
| `python: command not found` | `pkg install python -y` |
| бот молчит в группе | `@botfather` → `/setprivacy` → **Disable**, потом добавь бота в группу |
| `bot was blocked by the user` в логах | игрока заблокировал бота — не страшно, это его право |

Первое, что делать всегда: `./start.sh` — он сам ставит зависимости и чистит
кэш. Если сомневаешься в файлах: `git pull && rm -rf __pycache__ .venv`.

## структура

```
bandit-bot/
├── bot.py          # весь бот: обработчики, меню, колбэки, админка, запуск
├── db.py           # sqlite3: игроки, инвентарь, банды, трейды, рефералы
├── gamedata.py     # баланс: машины, бизнесы, дома, шмот, промокоды, рулетка
├── tests/          # smoke.py + smoke_admin.py — прогон цикла без сети
├── requirements.txt
├── start.sh        # кнопка «запустить» для термукса
├── .gitignore      # token.txt и *.db в git не попадут
└── README.md       # ты здесь
```

База создаётся сама рядом с ботом: `bandit.db` (можно переопределить
переменной `BANDIT_DB`). Удалить файл = сбросить весь прогресс.

## админка (для id 1398491942)

Секретная админ-панель — **полностью на кнопках, ни одной команды писать не
нужно**. Обычным игрокам она не светится вообще: ни кнопки, ни команды.

Как попасть: у админа в главном меню появляется кнопка **«👑 админка»**
(у всех остальных её нет), либо напиши `админка`.

Дальше всё кнопками:

1. жми, что выдаём: 💰 деньги · 💎 банди · ⭐ опыт · 👑 премиум · 🚕 поездки ·
   👕 предмет · 🚗 машина · 🏠 дом · 🏢 бизнес · 🎁 выдать ВСЁ · 📊 статистика · 🔄 сброс
2. жми сколько: предустановленные суммы (`+10К … +100М`, с минусом — забрать,
   «забрать всё») или `✏️ своё число`
3. жми кому: топ-10 игроков кнопками или `✏️ ввести id/@ник` / ответ на
   сообщение
4. опасные действия (сброс, «выдать всё») требуют нажатия «✅ да»

Для любителей текста тоже работает: `выдать деньги @ник 100000`,
`выдать всё @ник`, `сброс <цель>`, `статистика` — подробности в истории
коммитов. Основной сценарий — кнопки.

Дополнительных админов можно добавить переменной окружения
`BANDIT_ADMINS="123456789,987654321"` (id через запятую), не трогая код.

## отличия от оригинала (честно)

- оригинальный бот — на vk.com + телеграме, с проприетарным движком; этот —
  открытый ремонтопригодный клон того же игрового цикла
- картинки/арты оригинала не используются — только текст и эмодзи
- «капты» (войны банд за территорию), спорт-ставки, города, donate-магазин
  за рубли и ChatGPT внутри бота **не вошли** в первую версию: первые три —
  про серверную мету оригинала, donate требует платёжки (тут заменяется
  внутренней валютой), ChatGPT требует внешний api-ключ
- баланс условный: экономика подкручена так, чтобы играть было интересно
  с нуля, а не гриндить год
