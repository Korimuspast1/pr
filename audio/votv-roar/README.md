# Страшный рёв — 6 секунд

Один звуковой файл ровно на **6.000 с**: низкий звериный рёв с резким питч-дауном,
визгом и инфразвуковой «тряской». Вдохновлён атмосферой *Voices of the Void*, но
**ассеты игры не использовались** — всё синтезировано с нуля (`render.py`).

![Волна](waveform.png)

## Файлы

| Файл | Формат |
|---|---|
| `scary-roar-6s.wav` | PCM 16-bit, 44.1 кГц, стерео — основной файл для движка/видео |
| `scary-roar-6s.mp3` | MP3 192 kbps — для плеера и пересылки |
| `scary-roar-6s.ogg` | OGG Vorbis — для веба |
| `index.html` | Плеер с волной, повтором и кнопками скачивания |
| `render.py` | Генератор (numpy + scipy + soundfile + lameenc) |

Параметры: 6.000 с, пик −0.4 дБFS, RMS ≈ −18 дБFS, крест-фактор ≈ 7.7
(динамика сохранена: удары, провалы, затухание — без выжимающего компрессора).
Края файла затушены, щелчков нет.

## Как звучит

| Время | Что происходит |
|---|---|
| 0.0–0.4 с | вдох + удар 52 Гц, громкий старт |
| 0.4–1.7 с | основной крик: питч падает 195 → 90 Гц, форманты U→A→E |
| 1.7–3.2 с | второй выдох-толчок + отдельный высокий визг 560–1030 Гц |
| 3.2–4.6 с | низкое клокочущее урчание, vocal fry (субгармоника f0/2) |
| 4.6–6.0 с | предсмертный всхлип, затухание в реверб |

**Модель звука:** «источник + фильтр», как у настоящей глотки.
Источник — когерентный гармонический ряд (все гармоники в фазе, без случайных
фаз, которые превращают рык в шум), с джиттером и субгармоникой f0/2.
Фильтр — шесть формантных наборов U/A/E/O/U/R на каскадных резонаторах
`scipy.signal.iirpeak`, между которыми звук плавно морфится. Плюс отдельный
визговый голос, дыхание, суб-октава, инфразвук 29 Гц и convolution-реверб.

> ⚠️ Много суб-баса 25–60 Гц. Слушайте в наушниках или с сабвуфером, начните с
> небольшой громкости. Середина 200–1500 Гц добавлена, чтобы рёв читался и на
> маленьких колонках.

## Перегенерация

```bash
pip install numpy scipy soundfile lameenc
python render.py              # перезапишет WAV/MP3/OGG
python render.py --seed 777   # другой вариант (шум, джиттер, панорама)
```

Что крутить в `render.py`:

- `DUR` — длительность (по умолчанию 6.0 с).
- В `build_roar()`: блок 1 — питч-контур `f`; `STAGES` — последовательность
  гласных/формант; `knots_t/knots_a` — огибающая слогов; коэффициенты в блоке 8 —
  баланс «голос / визг / дыхание / суб».

## Локальный прослушиватель

```bash
cd audio/votv-roar
python3 -m http.server 8000 --bind 0.0.0.0
# открыть http://localhost:8000/
```

Можно свободно использовать в своих видео, модах и играх — это оригинальный
материал, а не рип звуков из игры.
