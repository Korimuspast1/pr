# Editor 1

Нативное приложение для Windows 10/11 x64 на Win32 и Rich Edit. Тёмный интерфейс со скруглёнными элементами, подсветкой при наведении и плавными переходами. Electron, браузер и сервер не используются. Режимы «Редактор» и «Чтение», поиск, создание и удаление заметок, импорт и экспорт UTF-8 Markdown/TXT. В режиме чтения заголовки и цитаты выделяются; это упрощённое отображение Markdown, а не полноценный Markdown-рендерер.

## Запуск

Запустите `Editor 1.exe`. Заметки автоматически сохраняются в `%APPDATA%\Editor1` отдельными UTF-8 файлами Markdown. Файлы не зашифрованы. Для резервной копии скопируйте эту папку. Импорт и хранение поддерживают UTF-8 файлы до 4 МБ.

- **Ctrl+N** — новая заметка
- **Ctrl+O** — импорт
- **Ctrl+S** — экспорт
- **F2** — переименовать

Сборка не подписана цифровой подписью, поэтому Windows может показать предупреждение SmartScreen.

## Сборка из исходного кода

На Linux с Zig (проверено с ziglang 0.17): `python3 -m pip install ziglang`, затем `./build.sh`. Скрипт кросс-компилирует оптимизированный Windows x64 PE-файл без отладочных символов. Нативная компиляция усложняет анализ исходного кода, но не может полностью предотвратить обратную разработку. Шифрование исходного кода или XOR не гарантирует защиты.

## Сторонние наработки

Для тёмного заголовка окна адаптирован фрагмент [ysc3839/win32-darkmode](https://github.com/ysc3839/win32-darkmode) (MIT). Уведомление об авторских правах и условия лицензии приведены в `THIRD_PARTY_LICENSE.txt`. Остальной интерфейс отрисовывается собственным кодом.
