# Editor 1 — версия 1.6

Нативный редактор заметок для Windows 10/11 x64 на Win32 и Rich Edit. Electron, браузер и сеть для работы не нужны.

## Запуск и хранение

Закройте старый Editor 1, распакуйте архив и запустите `Editor 1 v1.6.exe`. В заголовке указана версия 1.6. Заметки автоматически сохраняются в `%APPDATA%\Editor1` отдельными UTF-8 файлами Markdown. Они не зашифрованы. Для резервной копии скопируйте эту папку; старые заметки останутся доступны. Импорт поддерживает UTF-8 Markdown и TXT размером до 4 МБ, экспорт — Markdown и TXT.

## Возможности

- Несколько заметок, создание копии, переименование и удаление с подтверждением.
- Поиск по названиям и содержимому заметок. При большом числе крупных файлов поиск может занимать время.
- Панель Markdown: полужирный, курсив, заголовок, список, задача, цитата и ссылка. Для полужирного, курсива и ссылок можно выделить текст; заголовок и списки добавляются в начало текущей строки.
- Внизу — количество слов и знаков в исходном тексте (включая Markdown-разметку).
- Режим чтения упрощённо отображает заголовки, цитаты, обычные и списки задач, полужирный, курсив и встроенный код. Это не полный Markdown-движок: например, ссылки остаются в исходной записи.
- В **«Настройках»** выбираются размер и вид шрифта, межстрочный интервал и задержка автосохранения. Настройки хранятся локально в `%APPDATA%\Editor1\settings.ini` и применяются после нажатия «Применить».
- Плавная подсветка элементов и переключение режимов; учитывается системная настройка Windows для отключения анимаций. Ввод текста и системные диалоги не задерживаются анимацией.

## Клавиши

- **Ctrl+N** — новая заметка
- **Ctrl+D** — копия текущей заметки
- **Ctrl+F** или **Ctrl+K** — поиск заметок
- **Ctrl+B / Ctrl+I** — полужирный / курсив в редакторе
- **Ctrl+O** — импорт; **Ctrl+S** — экспорт
- **F2** — переименовать (Enter — сохранить, Esc — отменить)

## Режим разработчика

Откройте `Editor 1 Dev.bat` из распакованного архива или запустите `"Editor 1 v1.6.exe" -dev` из командной строки. Откроется отдельное окно журнала, а в заголовке появится `[DEV]`. Если окно журнала закрыто, **Ctrl+Shift+D** откроет его снова. События также дописываются в `%APPDATA%\Editor1\debug.log`; после закрытия программы файл можно удалить. Логи содержат события, ошибки, длительность сохранения и размеры документов, но не их названия или текст. В обычном режиме журнал не ведётся.

Сборка не подписана цифровой подписью, поэтому Windows может показать предупреждение SmartScreen. Стеклянный интерфейс — стилизация, а не материал Apple; динамического размытия рабочего стола нет.

## Сборка и проверка

На Linux с Zig (проверено с ziglang 0.17): `python3 -m pip install ziglang`, затем `./build.sh`. Независимые тесты логики: `for t in animation markdown preferences; do cc -Wall -Wextra -Werror tests/test_$t.c -o /tmp/test-$t && /tmp/test-$t; done`. Для проверки самого приложения нужна Windows или подходящая совместимая среда.

## Сторонние наработки

Тёмный заголовок адаптирован из [ysc3839/win32-darkmode](https://github.com/ysc3839/win32-darkmode) (MIT; `THIRD_PARTY_LICENSE.txt`), форма стекла — из [liquid-glass-windows-trial](https://github.com/oversmartnader/liquid-glass-windows-trial) (MIT), иконки основаны на [Lucide](https://github.com/lucide-icons/lucide) (ISC/MIT). Лицензии находятся в `assets/`; значок приложения создан специально для Editor 1. Исходные SVG находятся в `assets/icons/` и преобразуются командой `python3 generate_icons.py` (нужны `resvg-py` и Pillow); для обычной сборки эти пакеты не требуются.
