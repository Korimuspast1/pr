# Editor 1 — версия 1.5

Нативный редактор для Windows 10/11 x64 на Win32 и Rich Edit; Electron и браузер не используются. Заметки автоматически сохраняются на устройстве. В версии 1.5 добавлены плавные переходы кнопок, подсветки поиска и списка заметок и скользящий переключатель режимов. Приложение учитывает отключение анимаций в настройках Windows. Текстовый ввод и стандартные системные диалоги не задерживаются анимацией.

## Запуск

Закройте старый Editor 1, распакуйте архив и запустите `Editor 1 v1.5.exe`. В заголовке указана версия 1.5. Заметки хранятся в `%APPDATA%\Editor1` отдельными незашифрованными UTF-8 файлами Markdown. Для резервной копии скопируйте эту папку. Поддерживаются текстовые файлы UTF-8 размером до 4 МБ.

- **Ctrl+N** — новая заметка
- **Ctrl+O** — импорт
- **Ctrl+S** — экспорт
- **F2** — переименовать (Enter — сохранить, Esc — отменить)

## Режим разработчика

Для запуска с логами откройте `Editor 1 Dev.bat` из распакованного архива либо выполните из командной строки:

```cmd
"Editor 1 v1.5.exe" -dev
```

Откроется дополнительное окно журнала, а в заголовке приложения появится `[DEV]`. Закрытие окна журнала не закрывает редактор: чтобы снова его открыть, нажмите **Ctrl+Shift+D**. События также дописываются в `%APPDATA%\Editor1\debug.log`; файл можно удалить после закрытия приложения. Лог содержит события, ошибки, длительность сохранения и размеры документов, но не их названия или текст. В обычном режиме журнал не ведётся. Если файл журнала создать не удалось, предупреждение появится в окне журнала.

Сборка не подписана цифровой подписью, поэтому Windows может показать предупреждение SmartScreen. В режиме чтения отображение Markdown упрощённое. Визуальный эффект стекла — стилизация, а не материал Apple, без динамического размытия рабочего стола.

## Сборка и проверка

На Linux с Zig (проверено с ziglang 0.17): `python3 -m pip install ziglang`, затем `./build.sh`. Тест временной интерполяции: `cc -Wall -Wextra -Werror tests/test_animation.c -o /tmp/editor1-animation-test && /tmp/editor1-animation-test`. Исполняемый файл Windows можно запустить только на Windows или в подходящей совместимой среде.

## Сторонние наработки

Для тёмного заголовка окна адаптирован фрагмент [ysc3839/win32-darkmode](https://github.com/ysc3839/win32-darkmode) (MIT; `THIRD_PARTY_LICENSE.txt`). Форма стеклянных элементов адаптирована из [liquid-glass-windows-trial](https://github.com/oversmartnader/liquid-glass-windows-trial) (MIT), иконки основаны на [Lucide](https://github.com/lucide-icons/lucide) (ISC/MIT); лицензии находятся в `assets/`. Иконка приложения нарисована специально для Editor 1.

Исходные SVG находятся в `assets/icons/`; их можно изменить и заново преобразовать командой `python3 generate_icons.py` (нужны `resvg-py` и Pillow). Обычная сборка содержит сгенерированный `icons.h` и этих пакетов не требует.
