# 🧟 DEAD INSTINCT

**Пиксельный зомби-survival-horror для Android в духе The Walking Dead: инстинкты, тишина, шум, укрытия, голод, доверие группы и последствия решений.**

Это полная переработка исходной стратегии: вместо армий и городов — пять эпизодов о том, как выжить в мёртвом городе и не потерять себя.

## 📥 Скачать / установить

APK собирается автоматически в GitHub Actions и публикуется в **Releases**:

- открой [Releases](../../releases) → последний тег `dead-instinct-v*` → скачай `DeadInstinct-*.apk`;
- или в Actions → «Release Dead Instinct APK» → artifacts → `dead-instinct-apk`.

На телефоне: скачать `.apk` → открыть → разрешить установку из неизвестных источников.
Android 6.0+ (API 23), портретная ориентация, 72×72 тайла, ~10 МБ.

## 🎮 Что в игре

### Инстинкты (главная механика)
- **Чутьё** — пассивно: слышишь зомби за стенами, видишь свежие следы, чувствуешь направление угрозы.
- **Чувство беды (Q)** — замедляет время в 3 раза на 2 секунды и подсвечивает ближайшего заражённого.
- **Затаиться (E)** — замирание: зомби теряют след, если ты не двигаешься и выключил фонарь.
- **Отвести (X)** — банка/фальшфейер: шум уводит стаю в другую сторону.

### Шум — главный враг
| Действие | Слышно на |
|---|---|
| крадучись | ~0.5 тайла |
| шагом | 2 тайла |
| бегом | 14 тайлов |
| выстрел из пистолета | 34 тайла |
| выстрел из винтовки | 48 тайлов |
| визг крикуна | вся округа |

Зомби видят плохо (и почти не видят в темноте), но **слышат отлично**. Дождь глушит шаги, болото — тоже, но вода выдаёт.

### Зомби
ходячие · бегуны (быстрее тебя) · ползуны (в траве) · раздутые (кислота) · крикуны (зовут орду) · громилы (боссы)

### Группа и доверие
Мара (медик), Ян (снайпер), Вера (инженер), Дым (проводник), Стас (силач), Люда (разведчица) — каждый со своими навыками, репликами и мнением о твоих решениях. Доверие растёт от человечности и падает от жестокости и потерь. На нуле люди уходят в ночь.

### Выживание
- **Голод и жажда** — ешь и пей, иначе силы уходят.
- **Заражение** — растёт от укусов и кровотечения; бинты останавливают, антибиотики — надёжнее. 100% — конец.
- **Фонарь** — спасает от темноты, но свет в окнах видят все. Батарейки — расходник.
- **Убежище** — генератор (топливо), радио, кровать, верстак, ящики.
- **Выборы** — делиться припасами, уйти молча или забрать силой. Это меняет доверие, лут и концовку.

### Пять эпизодов
1. **Тихий час** — проснуться в квартире, выйти из дома, дойти до ворот.
2. **Аптека** — найти две аптечки, встретить чужих, решить их судьбу.
3. **Дождь и ток** — канистры, генератор, первый громила.
4. **Чужие** — торговый центр, живые люди страшнее зомби.
5. **Изолятор** — поликлиника, журнал изолятора, финал и одна из четырёх концовок (включая секретную).

## 🕹 Управление

**Телефон:** слева — стик движения, справа — стик камеры; тап по правой половине — удар/выстрел; кнопки — инстинкты, рюкзак, фонарь, крадучись, бег, «обыскать».

**ПК:** `WASD`/стрелки — ходьба, мышь — камера/удар, `Shift` — бег, `C` — крадучись, `E` — действие, `I` — рюкзак, `F` — фонарь, `Q` — чувство беды, `R` — затаиться, `X` — бросить банку, `Esc` — пауза.

## 🛠 Технологии

- HTML5 Canvas + чистый JavaScript, без сборки и зависимостей в рантайме.
- Вся графика — **процедурный пиксель-арт** в коде (персонажи, зомби, портреты, тайлы, иконки).
- Весь звук — **синтез WebAudio** на лету (дождь, ветер, шаги, выстрелы, дыхание, сердцебиение).
- Карта: генерация кварталов, домов с дверями и стёклами, река, болото, поиск пути A*, линия обзора.
- Свет: маска тьмы + динамические источники, туман памяти, дождь, молнии.
- Android-оболочка: WebView без разрешений (нет интернета, нет доступа к файлам, нет JS-мостов в систему).

```
dead-instinct/
  www/                 # игра (открывается прямо в браузере)
    index.html
    css/style.css
    fonts/unifont.woff # пиксельный шрифт GNU Unifont (GPL+FE), полная кириллица
    js/
      data.js          # баланс, предметы, зомби, главы, тексты
      map.js           # генерация города, дома, двери, A*, линия обзора
      sprites.js       # процедурный пиксель-арт
      audio.js         # синтез звука
      story.js         # сюжет, цели, диалоги, выборы, концовки
      game.js          # ядро: симуляция, инстинкты, зомби, доверие
      render.js        # рендер и свет
      ui.js            # HUD, меню, рюкзак, диалоги, заставки
      main.js          # ввод и главный цикл
  android/             # сборка APK без Gradle (aapt2 → javac → d8 → apksigner)
  tools/               # тесты и генераторы (не входят в APK)
```

## ▶ Запуск в браузере

```bash
cd dead-instinct
python3 -m http.server 8080 -d www
# открыть http://localhost:8080
```

## 📱 Сборка APK

```bash
cd dead-instinct
sh android/build.sh      # нужны JDK 11+ и Android SDK 34, см. android/README.md
# → release/DeadInstinct-1.0.0.apk
```

Автоматически то же делает [`.github/workflows/dead-instinct-release.yml`](../.github/workflows/dead-instinct-release.yml): на каждый пуш собирает APK,
на тег `dead-instinct-v*` — публикует релиз.

## ✅ Тесты

```bash
npm i @napi-rs/canvas jsdom     # только для тестов
node tools/soak.js              # 5 эпизодов × 3 сида по 150 с + финалы + сохранения
node tools/uitest.js            # весь UI в jsdom: меню → игра → смерть → перезапуск
node tools/screens.js           # реальные скриншоты в headless Chromium
node tools/gen_icons.js         # иконки лаунчера
```

## ⚠️ О игре

Игра — художественный вымысел. Все персонажи, события и «инстинкты» придуманы.
Она не про зомби как таковых, а про людей, которые остаются людьми, когда всё вокруг перестаёт быть живым.
