# МКАД Мото — MKAD Moto Rider

Аркадная 3D-гонка на мотоцикле по кольцевой автотрассе (в духе МКАД) на движке **Godot 4** (проверено на 4.3, подойдёт любой Godot 4.2+).

Едешь по кольцу, разгоняешься, тормозишь, перестраиваешься между полосами, объезжаешь плотный трафик из настоящих детализированных 3D-моделей машин, мимо рекламных щитов, фонарей, отбойников, километровых знаков и высоток на горизонте.

## Как запустить

1. Установи [Godot 4](https://godotengine.org/download) (Standard-версия, не .NET — проект использует только GDScript).
2. Открой Godot → **Import** → укажи файл `project.godot` из этой папки.
3. При первом открытии Godot немного посчитает импорт текстур/моделей — это нормально.
4. Нажми **Run** (F5, главная сцена уже назначена — `scenes/Main.tscn`).

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `↑` | Газ |
| `S` / `↓` | Тормоз / задний ход |
| `A` / `D`, `←` / `→` | Руль (поворот) |
| `Пробел` | Ручной тормоз (резкая остановка) |
| `H` | Гудок (зарезервировано) |
| ЛКМ (удержать) + мышь | Довернуть камеру вокруг байка |
| `C` | Переключить дальний/ближний план камеры |
| `R` | Сбросить мотоцикл обратно на дорогу (если застрял/улетел на траву) |

Внизу экрана — спидометр (км/ч), одометр (пройденные километры) и счётчик кругов по кольцу.

## Что внутри и откуда ассеты

- **Мотоцикл** — готовая (не процедурная) 3D-модель **vehicle-motorcycle.glb** из официального репозитория **Kenney "Starter Kit: Racing"** (github.com/KenneyNL/Starter-Kit-Racing, модели и звуки — CC0): отдельные узлы для рамы/бака/вилки и обоих колёс, что позволяет анимировать качение колёс и поворот руля. Звук двигателя и юза шин — тоже готовые CC0-сэмплы оттуда же. Поверх модели добавлен небольшой процедурный райдер в шлеме (капсулы/сферы), так как готовой фигуры человека в наборе нет. Код — `scripts/motorcycle.gd`.
- **Машины трафика** — реальные детализированные модели из бесплатного набора **Kenney "Car Kit"** (лицензия **CC0 / общественное достояние**, автор [Kenney](https://kenney.nl)): седаны, спорткары, внедорожники, такси, фургоны, — с собственными текстурами.
- **Отбойники, фонари, рекламные щиты** — модели из набора **Kenney "Racing Kit"** (тоже CC0).
- **Дорога, разметка, разделительный барьер, портальные указатели «МКАД», километровые столбики, здания, деревья, трава** — процедурная геометрия, сгенерированная кодом (`scripts/road_builder.gd`).
- **Текстуры асфальта, травы, фасадов зданий и берёзовой коры** — сгенерированы отдельно и лежат в `assets/textures/`.

Список используемых файлов Kenney и их путей — см. `CREDITS.md`.

## Структура проекта

```
project.godot
icon.svg
scenes/
  Main.tscn          — точка входа, всё остальное строится кодом в main.gd
  Motorcycle.tscn     — игрок (CharacterBody3D + motorcycle.gd)
  TrafficCar.tscn     — AI-машина (CharacterBody3D + traffic_car.gd)
scripts/
  game_manager.gd     — автозагружаемый синглтон Game: константы кольца МКАД и общий стейт
  main.gd             — окружение, спавн игрока/камеры/трафика, HUD
  road_builder.gd      — процедурная трасса, барьеры, освещение, здания, деревья
  motorcycle.gd        — модель мотоцикла + управление/физика
  traffic_car.gd       — AI трафика по кольцу
  chase_camera.gd      — камера от третьего лица
  hud.gd               — интерфейс (спидометр, одометр, круги)
assets/
  kenney/car/...       — модели машин (CC0, Kenney)
  kenney/racing/...    — отбойники/фонари/билборды (CC0, Kenney)
  textures/...          — сгенерированные текстуры
```

## Настройка трассы

Все параметры кольца (радиус, ширина полос, число полос, скорость трафика) вынесены в константы `scripts/game_manager.gd` и `scripts/main.gd` — их легко поменять, чтобы сделать трассу длиннее/шире или добавить больше машин.
