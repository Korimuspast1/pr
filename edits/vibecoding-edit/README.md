# ГАЙД НА ВАЙБКОДИНГ — 60-секундный эдит

Вертикальный (1080×1920, 30 fps, ровно 60 с) монтаж по мотивам видео
[«ГАЙД НА ВАЙБКОДИНГ»](https://www.youtube.com/watch?v=40-Bp04QC6w) — канал
[моно](https://www.youtube.com/@mono-tubes) (16:45, опубликовано 26.11.2026).

**Готовый файл:** `out/mono-vajbkoding-edit-60s.mp4`

---

## Что внутри

| время | секция | что происходит |
|-------|--------|----------------|
| 0:00–0:04 | интро | карточка «Что создадим?», титр «ГАЙД НА ВАЙБКОДИНГ» |
| 0:04–0:15 | билд | Minecraft-стол, обложки игр, глитч-монтаж GTA, самолёт, реакция, лого Claude/OpenAI |
| 0:15–0:30 | дроп 1 | 16 склеек по 0.94 с: цены, слайды, обложки, вертолёт, 3D-рендер |
| 0:30–0:37 | брейкдаун | «ЕСЛИ УМЕЕШЬ ПОЛЬЗОВАТЬСЯ ИИ-АГЕНТАМИ… УМЕЕШЬ ЛИ ТЫ ВАЙБКОДИТЬ?» |
| 0:37–0:52 | дроп 2 | второй круг: терминал/тесты, MCP, Telegram, GTA, Minecraft-сетап |
| 0:52–1:00 | аутро | титр + финальная плашка «СМОТРИ ПОЛНОСТЬЮ / моно» |

Всего 45 кадров, все склейки стоят на сетке **128 BPM** (2 или 4 бита на кадр),
поэтому монтаж попадает в бит музыки.

## Эффекты

- `punch_in` / `punch_out` — плавный наезд/отъезд + микротряска;
- `pan_l` / `pan_r`, `tilt_up` / `tilt_down` — движение камеры по кадру;
- `glitch` — rgb-сдвиг, шум, дрожание кадра;
- `fit` — для скриншотов: кадр целиком в вертикали на размытой подложке, чтобы текст читался;
- белые вспышки на старте дропов, грейн, виньетка, unsharp, лёгкий подъём контраста и сатурации;
- звук нормализован в `-14 LUFS` (стандарт для Reels/Shorts/TikTok).

## Музыка

`make_music.py` синтезирует трек с нуля (numpy, без сэмплов): 128 BPM, A minor,
Am–F–C–G, кик/клэп/хэты/бас/арпеджио, райзеры перед дропами, сайдчейн,
ровно 60.000 с. Авторских прав нет — это полностью сгенерированный звук.

## Как пересобрать

```bash
cd edits/vibecoding-edit
python3 make_music.py out/music.wav                 # 3 с
python3 make_edit.py                                # ~3.5 мин на 2 ядрах
python3 make_edit.py --preview                      # первые 4 кадра, быстро
SRC=/путь/к/другому/видео.mp4 python3 make_edit.py  # другой источник
```

Шот-лист — список `SHOTS` в `make_edit.py`:
`(время_в_источнике, биты, стиль, подпись, кегль)`.

## Как был получен исходник

Песочница, в которой шла работа, выпускает трафик только на pypi/npm/github —
YouTube оттуда недоступен. Поэтому видео скачивал GitHub Actions-раннер
(`.github/workflows/dl-video.yml`): он поднимает Cloudflare WARP в proxy-режиме,
через него `yt-dlp` тянет поток 1080p, перекодирует в 720p и коммитит файл в ветку.
Готовый файл лежит в `edits/source/mono-vajbkoding.mp4`.
