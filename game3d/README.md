# ПЕСОЧНИЦА 3D — кровавый sandbox

Трёхмерная версия песочницы: ты не персонаж, а наблюдатель с инструментами.
Спавни людей, режь конечности, стреляй, смотри на рэгдолл, кровь и данные
каждого тела. Всё в метрах, Y — вверх, +Z — вперёд.

Открывается по адресу `http://localhost:5174` (2D-версия живёт рядом, в `../game`, порт 5173).

```bash
cd game3d
node server.mjs          # → http://localhost:5174
```

Готовые рендеры (без браузера и GPU) лежат в `shots/`: оружие, человек, лицо,
рэгдолл и несколько ракурсов карты с тенями и ночным небом.

Зависимостей для запуска нет: `three` лежит в `vendor/three.module.js`.
Для тестов нужен `npm i` (jsdom).

## Управление

| Клавиша | Действие |
| --- | --- |
| **Q** | резать (зажать ЛКМ и вести по телу) |
| **W** | стрелять (ЛКМ — огонь) |
| **E** | осмотр: наведи или кликни, чтобы закрепить панель |
| **R** | спавн: клик по земле; **Shift**+клик — сразу с оружием |
| **T** | тянуть тело (рэгдолл тянется за курсором) |
| **Y** | лечить (останавливает кровь, залечивает раны, выводит из шока) |
| **U** | удалить человека |
| **1–8** | кулаки, нож, мачете, топор, катана, пистолет, ПП, дробовик, СВД |
| **ПКМ** + мышь | вращать камеру |
| **СКМ** / **стрелки** | двигать камеру по земле (Shift — быстрее) |
| **колесо** | зум |
| **Space** | темп: x1 → x0.35 → x0.12 |
| **F** | добавить вооружённого жителя |
| **Backspace** | убрать трупы |
| **G** | стереть кровь |
| **P / M / H** | пауза, звук, справка |
| **Esc** | снять закреплённый осмотр |

## Что считается «реалистично»

**Ткани.** У каждой из 10 частей тела своя структурная прочность (`struct`, 0…1.4).
Удар добавляет повреждение ткани, боль и рану; раны дают кровотечение, которое
постепенно сворачивается. Артериальное ранение даёт фонтан и резко ускоряет потерю крови.

**Конечности не отрываются с первого удара.** Пока `struct < 0.45`, шанс отрыва равен нулю.
Дальше он растёт от разрушения тканей, числа порезов и типа оружия: ножу нужно
несколько движений, мачете — меньше, топор ломает кость и отрывает быстрее.
Пули рвут конечности редко (множитель 0.4), голова отделяется только при
разрушении черепа. У культи своё кровотечение: плечо ~45 мл/с, бедро ~70 мл/с.

**Смерть не мгновенная.** Корпусное попадание снимает здоровье и запускает
кровотечение; ниже 3000 мл крови начинается шок (падение здоровья), при
`health < 16`, `blood < 1400` или сильной боли человек теряет сознание и падает.
Голова — множитель ×2.6, корпус ×1, остальные части ×0.4: чтобы убить, нужно
либо попадание в голову, либо несколько корпусных, либо дать крови вытечь.

**Физика.** Рэгдолл — PBD-скелет из 16 точек с ограничениями дистанций,
лимитами локтей/коленей, трением об асфальт и засыпанием. Труп можно тащить,
поднять он не может; живой и здоровый через пару секунд встаёт сам.

**Кровь.** 2600 GPU-частиц (капли, туман, искры, пыль), до 900 декалей на земле,
320 кусков плоти и костей, брызги из культей, кровавые пятна на теле и видимые
обрубки. Кровь на теле и полу не исчезает, пока её не сотрёшь (G).

**Стрельба.** У каждого ствола своя скорострельность, магазин, разброс, время
перезарядки и импульс; дробовик стреляет 9 дробинами, СВД пробивает насквозь
конечности, ПП ведёт автоматический огонь. Пули — трассеры с попаданием в
ближайшую конечность по геометрии луча.

## Карта

Двор-уровень 60×56 м внутри квартала: три здания (жилой дом с пожарной лестницей,
склад с воротами и доком, офис с навесом), гаражи, бытовка, сторожка, автобусная
остановка, заборы с воротами, контейнеры (один составлен вторым ярусом), грузовик,
три машины (одна сгоревшая), отбойники, ящики, паллеты, покрышки, бочки (две горят),
фонари и прожекторы на стенах.

- **Стены не пропускают.** `map.js` собирает AABB-коллайдеры (с учётом поворота)
  и раскладывает их по сетке 4 м; `world.queryColliders` достаёт только ближние.
  Стоящий человек выталкивается из геометрии (`resolvePoint`), точки рэгдолла —
  тоже, ходьба ИИ проверяет `blocked` и скользит вдоль стены.
- **Спавн без глюков.** Точки спавна размечены на свободных местах; если клик
  пришёлся внутрь стены, человек появится на ближайшей свободной точке.
- **Свет.** Ночная сцена: направленный «лунный» свет с картой теней 2048²,
  полусферический свет, фонари с мерцанием и костры в бочках.
- Поверхность двора размечена пятнами грунта и ремонтными заплатками, есть лужи,
  а сетка-рабица собрана из настоящих прутков (один draw call).

## Интерфейс

- Слева — инструменты с подсказкой по каждому.
- Снизу — панель оружия с остатком патронов.
- Справа — инспектор: здоровье, кровь в литрах, боль, скорость кровопотери,
  оружие и магазин, состояние каждой конечности (цела / ушиб / рана / перелом /
  оторвана), артерии, число ран, поведение ИИ, причина смерти.
- Слева снизу — журнал событий (кто погиб, кому что оторвало).

## Структура

```
game3d/
  index.html          разметка и стили интерфейса
  server.mjs          статический сервер без зависимостей (порт 5174)
  vendor/three.module.js
  src/
    main.js           сцена, камера, инструменты, стрельба, HUD, инспектор
    world.js          окружение, свет, кровь, декали, куски, трассеры, вспышки
    human.js          скелет, поза, IK, PBD-рэгдолл, раны, смерть, ИИ
    weapons3d.js      9 видов оружия и их 3D-модели
    map.js            карта уровня: здания, реквизит, свет, коллайдеры, точки спавна
    textures.js       процедурные текстуры (асфальт, бетон, кирпич, металл, дерево)
    util3.js          математика: лучи, отрезки, углы
    audio.js          синтезированный звук на WebAudio
  test/
    sim.mjs           headless-симуляция: геометрия, физика, кровотечение, ИИ, коллизии
    ui.mjs            прогон настоящего main.js в jsdom (без GPU)
    raster.mjs        софт-растеризатор (z-буфер, тени, перспектива, PNG)
    render-models.mjs рендер всех моделей и карты в shots/
```

## Тесты

```bash
cd game3d
npm i
npm test          # симуляция
npm run test:ui   # интерфейс и инструменты
npm run test:all
```

`sim.mjs` проверяет математику луча, стойку, попадания, отрыв конечностей,
рэгдолл на земле, смерть от головы, перестрелку ИИ, данные инспектора, а также
карту: наличие коллайдеров, свободные точки спавна, выталкивание из стены и то,
что человек не проходит сквозь забор.
`ui.mjs` поднимает `index.html` в jsdom с подменённым рендерером и прогоняет
все инструменты, клавиши, панели и оружие.

```bash
node test/render-models.mjs   # → shots/*.png (27 картинок)
```

WebGL в этом окружении недоступен, поэтому модели проверяются собственным
софт-растеризатором: он умеет перспективу, z-буфер, направленные тени с PCF,
туман и ночное небо, так что по картинкам видно силуэты оружия, позу человека
и то, как читается карта с уровня глаз.
