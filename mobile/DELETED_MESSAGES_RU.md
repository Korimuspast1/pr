# DeletedMessageMarker для Discord Android

Плагин как в AyuGram: удалённые сообщения остаются прямо в чате и получают пометку `(deleted)`. Редактированные сообщения могут показываться как старый текст зачёркнутым + новый текст.

Поддерживаемые загрузчики:

- Revenge
- Bunny
- Vendetta / Pyoncord-совместимые клиенты

## Установка

Discord Android → Settings → Plugins → `+` / Install plugin:

```text
https://cdn.jsdelivr.net/gh/Korimuspast1/pr@arena/01a0e825-pr/mobile/dist/deleted-message-marker
```

Если нужен manifest:

```text
https://cdn.jsdelivr.net/gh/Korimuspast1/pr@arena/01a0e825-pr/mobile/dist/deleted-message-marker/manifest.json
```

## Что умеет

- оставляет удалённые сообщения прямо в чате;
- добавляет пометку `(deleted)`;
- красная подсветка строки удалённого сообщения;
- история редактирования: старый текст зачёркнут, новый ниже;
- жёлтая подсветка отредактированных сообщений;
- настройка: показывать в ЛС / серверах;
- настройка: игнорировать ботов;
- настройка: игнорировать свои сообщения;
- настройка: не сохранять сообщения, которые ты удалил сам;
- сохраняет медиа/вложения при edit, где возможно.

## Важно

- Плагин не восстанавливает старые сообщения до установки. Он может сохранить только то, что телефон уже получил.
- Всё локально, ничего не отправляется на сервер.
- После перезапуска Discord пометки могут пропасть из старых строк, потому что inline-режим работает через память клиента.
- Клиентские моды Discord могут нарушать ToS Discord — используй на свой риск.
