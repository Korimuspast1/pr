# OurCord Loader
Android Xposed/LSPatch loader for OurCord. It injects the bundled OurCord runtime before Discord's React Native bundle, manages runtime updates from this repository, and exposes the native bridge required by plugins, themes, fonts, and safe mode.

Built as part of `.github/workflows/ourcord-v2.yml`. Licensed under GPL-3.0; see `LICENSE` and `UPSTREAM.md`.
