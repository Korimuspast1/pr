# Смайлики 😊

Маленький учебный язык программирования, в котором все ключевые слова — эмодзи.
Внутри — настоящий интерпретатор: лексер → рекурсивный парсер → дерево → вычисление,
с областями видимости, функциями, рекурсией, циклами и понятными ошибками по-русски.

```smile
🙈 Привет, мир на смайликах
📦 имя ⬅ "мир"
🗣 "Привет, " ➕ имя ➕ "! 😊"

🎁 квадрат(n)
  ↩ n ✖ n
🔚

📦 i ⬅ 1
🔁 i ⬇🟰 5
  🗣 квадрат(i)
  i ⬅ i ➕ 1
🔚
```

Вывод:

```
Привет, мир! 😊
1
4
9
16
25
```

## Что внутри

| Файл | Назначение |
| --- | --- |
| [`smiley.py`](smiley.py) | Интерпретатор и CLI на Python (стандартная библиотека, без зависимостей) |
| [`web/`](web/) | Песочница в браузере: тот же язык, реализованный на JavaScript |
| [`examples/`](examples/) | Примеры программ |
| [`tests/`](tests/) | 42 теста на `unittest` |

## Быстрый старт

```bash
# выполнить файл
python3 smileylang/smiley.py run smileylang/examples/hello.smile

# выполнить код из строки
python3 smileylang/smiley.py -c '🗣 "Привет 😊"'

# интерактивный режим (пустая строка — выполнить накопленное, «выход» — выйти)
python3 smileylang/smiley.py repl

# посмотреть, как программа разбирается на токены
python3 smileylang/smiley.py tokens smileylang/examples/fizzbuzz.smile
```

Запуск песочницы в браузере:

```bash
cd smileylang/web && python3 -m http.server 8000
# открыть http://localhost:8000
```

## Синтаксис

Каждая команда — на своей строке; `;` работает как перевод строки.
У всех ключевых слов есть ASCII- и русские синонимы, так что программу можно
набирать на обычной клавиатуре.

### Переменные и вывод

| Смайлики | ASCII | Русский | Что делает |
| --- | --- | --- | --- |
| `📦 имя ⬅ значение` | `let имя = значение` | `пусть` | объявить переменную |
| `имя ⬅ значение` | `имя = значение` | — | присвоить новое значение |
| `🗣 a, b` | `print a, b` | `сказать` | напечатать значения через пробел |

```smile
📦 счёт ⬅ 10
счёт ⬅ счёт ➕ 5
🗣 "Итого: " ➕ счёт
```

### Условия

```smile
❓ x ⬆ 10 🤔          🙈 if x > 10 then
  🗣 "много"
🙃 ❓ x ⬆ 5 🤔        🙈 else if ...
  🗣 "средне"
🙃
  🗣 "мало"
🔚                    🙈 end
```

`🤔` (`then`) можно опускать. Ветка `🙃` необязательна, `🙃 ❓` делает цепочку «иначе если».

### Циклы

| Смайлики | ASCII | Что делает |
| --- | --- | --- |
| `🔁 условие … 🔚` | `while` | пока условие истинно |
| `🔂 5 … 🔚` | `repeat` | повторить тело 5 раз |
| `💔` | `break` | выйти из цикла |
| `⏭` | `continue` | перейти к следующей итерации |

```smile
🔂 3
  🗣 "😊" ✖ 3
🔚
```

### Функции

```smile
🎁 факториал(n)       🙈 func факториал(n)
  ❓ n ⬇🟰 1 🤔
    ↩ 1               🙈 return
  🔚
  ↩ n ✖ факториал(n ➖ 1)
🔚

🗣 факториал(10)      🙈 3628800
```

Функция без `↩` возвращает `🤷`. Замыкания работают: функция видит переменные
того места, где её объявили.

### Выражения

| Операция | Смайлики | ASCII |
| --- | --- | --- |
| сложение (и склейка строк) | `➕` | `+` |
| вычитание | `➖` | `-` |
| умножение (и повтор строки) | `✖` или `✖️` | `*` |
| деление | `➗` | `/` |
| остаток | `📐` | `%` |
| равно / не равно | `🟰` / `🚫` | `==` / `!=` |
| больше / меньше | `⬆` / `⬇` | `>` / `<` |
| больше-или-равно / меньше-или-равно | `⬆🟰` / `⬇🟰` | `>=` / `<=` |
| и / или / не | `🤝` / `🔀` / `🙅` | `and` / `or` / `not` |
| истина / ложь | `✅` / `❌` | `true` / `false` |

Скобки `( )` работают как обычно. `🤝` и `🔀` вычисляются лениво (короткое замыкание),
так что `❌ 🤝 (1 ➗ 0)` не падает.

### Значения

- числа: `42`, `3.5`, `1_000`
- строки: `"текст"` или `«текст»`, с экранированием `\n`, `\t`, `\"`, `\uXXXX`
- логика: `✅` и `❌` (печатаются именно так)
- «ничего»: `🤷` (результат функции без `↩`)

`➕` склеивает строки, `✖` повторяет: `"ха" ✖ 3` → `хахаха`.

### Встроенные функции

| Функция | ASCII | Что делает |
| --- | --- | --- |
| `длина(x)` | `len` | длина строки |
| `строка(x)` | `str` | превратить в строку |
| `число(x)` | `int` | превратить в число |
| `случайное(от, до)` | `random` | случайное целое в диапазоне |
| `спросить("Вопрос? ")` | `input` | спросить строку у пользователя |
| `время()` | `time` | текущее время в секундах |
| `верхний(x)` / `нижний(x)` | `upper` / `lower` | регистр строки |
| `круглое(x)` | `round` | округлить |

### Комментарии

`🙈`, `#` и `//` — до конца строки.

## Ошибки

Ошибки объясняются по-русски и указывают строку:

```
😵 Строка 4: переменная «возраст» не найдена
😵 деление на ноль — так нельзя 🙃
😵 Строка 2: цикл 🔁 не закрыт: не хватает 🔚
😵 🤯 программа слишком долго работает: превышен лимит шагов (2000000). Похоже на бесконечный цикл.
```

Предохранители: лимит шагов (по умолчанию 2 000 000, флаг `--max-steps`) и лимит
вывода (100 000 строк) — чтобы случайный бесконечный цикл не подвесил всё вокруг.

## Разработка

```bash
# тесты
cd smileylang && python3 -m unittest discover -s tests -v

# проверка синтаксиса
python3 -m py_compile smileylang/smiley.py
```

Тесты в браузерной песочнице (если установлен Node.js и `jsdom`):

```bash
cd smileylang/web && node --input-type=module -e '
import { execute } from "./smiley.js";
console.log(execute(`🗣 "работает 😊"`).output);'
```

## Как это устроено

1. **Лексер** идёт по тексту по code point'ам и узнаёт эмодзи-ключи (`📦`, `🗣`, `⬆🟰`…),
   а также ASCII- и русские синонимы. Необязательные селекторы вариации (U+FE0F) игнорируются,
   поэтому `✖` и `✖️` — один и тот же оператор.
2. **Парсер** — рекурсивный спуск по приоритетам: `🔀` → `🤝` → `🙅` → сравнения → `➕➖` → `✖➗📐` → вызовы.
3. **Интерпретатор** обходит дерево. Циклы и `💔`/`⏭` реализованы внутренними сигналами,
   функции — замыканиями над окружением, `↩` — исключением, которое ловится на границе вызова.

Python-версия — эталон: `smiley.py`. JavaScript-версия в `web/smiley.js` повторяет её
поведение для песочницы в браузере.
