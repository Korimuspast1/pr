# bassboost

Скрипт для **Termux** (и любого Linux с ffmpeg): даёшь путь до песни — mp3, flac, wav, m4a, ogg или видео с музыкой (mp4, mkv, webm…) — а на выходе получаешь готовый **bass boosted** файл. Всё определяется автоматически.

## Что делает автоматически

- Находит аудиодорожку и (если есть) видеодорожку — видео **копируется без перекодирования**, бустится только звук. Файл с **обложкой альбома** (mp3 с картинкой) считается музыкой, а не видео — результат останется mp3 и обложка сохранится.
- Выбирает формат результата сам: вход `flac` → `flac`, `.mp4` → видео сохраняется, «просто файл с видео, а нужен звук» → `--audio-only` → `mp3` (или `-o out.m4a`).
- Называет результат сам: `track_bassboosted.mp3` рядом с оригиналом. Существующие файлы **не перезаписывает** — добавляет `_2`, `_3`…
- Цепочка обработки: срез саб-шума (highpass 30 Гц) → бас-полка на 105 Гц → компрессор → нормализация громкости до −14 LUFS (как в стримингах) → лимитер без клиппинга.
- Если `ffmpeg` не установлен — в Termux скрипт **сам поставит** его через `pkg install ffmpeg`.
- Если в ffmpeg нет какого-то кодека (например, libmp3lame) — сам подберёт доступный (aac) и поменяет расширение.

## Установка в Termux

```bash
pkg install git
git clone <url-этого-репозитория>
cd репозиторий/bassboost
chmod +x bassboost.sh
```

Или просто скопируй `bassboost.sh` в телефон и `chmod +x bassboost.sh`.

Хочешь вызывать как команду из любого места:

```bash
mkdir -p ~/bin && cp bassboost.sh ~/bin/bassboost && chmod +x ~/bin/bassboost
# теперь просто: bassboost /sdcard/Music/song.mp3
```

## Использование

```bash
# самое простое — путь к файлу:
./bassboost.sh /sdcard/Music/song.mp3

# видео с музыкой — видео сохранится, звук станет бассистее:
./bassboost.sh /sdcard/Download/video.mp4

# сила буста:
./bassboost.sh -s light song.flac    # +6 дБ — аккуратно
./bassboost.sh -s medium song.flac   # +10 дБ — по умолчанию
./bassboost.sh -s heavy song.flac    # +15 дБ — для басхеда
./bassboost.sh -s 13 song.wav        # точный буст в дБ (-30…+30)

# только звук из видео:
./bassboost.sh --audio-only video.mp4              # → video_bassboosted.mp3
./bassboost.sh --audio-only -o готовый.m4a video.mp4

# своё имя/путь результата:
./bassboost.sh -o /sdcard/Music/ready.mp3 song.flac

# без нормализации громкости (если нужно «как есть, только бас»):
./bassboost.sh --no-loudnorm song.mp3

# справка:
./bassboost.sh --help
```

Если телефон ругается на путь с пробелами или кириллицей — бери его в кавычки: `./bassboost.sh "/sdcard/Music/моя песня (2024).mp3"`.

## Требования

- Termux (Android) или любой Linux/macOS с bash
- ffmpeg (+ желательно ffprobe — он в том же пакете `ffmpeg`); скрипт умеет работать и без ffprobe, через разбор вывода ffmpeg

## Проверка / тесты

Скрипт проверен на синтетических файлах: wav/flac/mp3/ogg/opus/mp4/webm, с видео и без, с обложкой альбома, с коллизиями имён, с битыми и беззвучными файлами, с файлами без расширения. Буст низких частот подтверждается замером (50 Гц синус: −21 dB → −9 dB при `heavy`).

## Как это звучит

Цепочка: `highpass 30 Гц → bass shelf +N дБ @ 105 Гц → компрессор 4:1 → loudnorm −14 LUFS → лимитер −0.4 dBFS`. Бас поднимается, но пики ограничены лимитером, поэтому клиппинга не будет; громкость выравнивается под стриминговый стандарт (−14 LUFS).
