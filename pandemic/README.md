# ПАНДЕМИЯ — симулятор патогена

Браузерная игра в духе Plague Inc: вы создаёте штамм, развиваете его за очки ДНК
и пытаетесь уничтожить человечество раньше, чем ВОЗ закончит работу над лекарством.

Никаких сборок и зависимостей — чистые HTML/CSS/JS. Достаточно открыть `index.html`.

```bash
# вариант 1: просто открыть файл
xdg-open index.html

# вариант 2: локальный сервер (если браузер капризничает с file://)
python3 -m http.server 8000
# затем http://localhost:8000
```

## Что внутри

- **Карта мира** из 175 стран (Natural Earth 110m, проекция Миллера) — страны
  заливаются тепловой картой по доле погибших, пульсирующие очаги показывают активные вспышки.
- **5 патогенов** с разными характерами: вирус, бактерия, грибок, паразит, прион.
- **3 уровня сложности**, влияющих на скорость реакции мира, разработку лекарства и доход ДНК.
- **46 улучшений** в трёх ветках: передача, симптомы, способности — с зависимостями в дереве.
- **Случайные мутации**: бесплатный симптом время от времени, чаще у вирусов.
- **Реакция государств**: страны обнаруживают вспышку (порог зависит от заметности симптомов
  и скрытности патогена), вводят меры и закрывают границы.
- **Лекарство**: прогресс растёт от богатых стран с высокой реакцией, замедляется
  сложностью патогена и устойчивостью к препаратам. 100% — новые заражения прекращаются.
- **Демография планеты**: здоровые / болеющие / погибшие / переболевшие и топ-8 очагов.
- **Управление**: пауза и скорости 1×/2×/4×, горячие клавиши (пробел, 1, 2, 3),
  клик по стране — подробности, клик по очагу в списке — подсветка страны.
- Звуковые эффекты на WebAudio (без файлов), адаптивная вёрстка для телефона.

## Структура

```
index.html            разметка интерфейса
css/style.css         оформление (тёмный «лабораторный» стиль)
js/data.js            контент: патогены, сложности, дерево улучшений
js/sim.js             вся математика эпидемии (без DOM, работает в Node)
js/ui.js              карта, панели, ввод, звук, игровой цикл
data/world.js         сгенерированная геометрия и демография 175 стран
tools/build-world.mjs генератор data/world.js из открытых данных
tools/test.mjs        проверки инвариантов симуляции
tools/simulate.mjs    headless-прогон эпидемии в консоли
```

## Инструменты

```bash
node tools/test.mjs        # 10 проверок: инварианты, баланс, детерминизм
node tools/simulate.mjs    # прогон «стратегии» и лог по дням
node tools/simulate.mjs balanced fungus brutal IDN
```

Пересобрать карту (нужны npm-пакеты `world-atlas`, `topojson-client`,
`world-countries`, `country-json`):

```bash
npm init -y
npm i world-atlas@2 topojson-client@3 world-countries@5 country-json@2
node tools/build-world.mjs
```

## Как это считается (кратко)

Для каждой страны хранится накопленная доля заражённых и считается логистический рост:

```
exp += exp * β * (1 - exp / pop)
β = (base + заразность) * климат * плотность * богатство * реакция страны * «эффект основателя»
```

Смерти и выздоровление снимаются с текущих больных (`inf = exp - dead - rec`),
летальность зависит от симптомов и качества медицины в стране. Между странами патоген
переходит по суше (соседи), по воздуху (богатые хабы и уровень воздушной передачи)
и по морю (порты, уровень водной передачи); закрытые границы режут эти шансы.

Баланс проверяется headless-прогонами: агрессивная стратегия обычно выигрывает на
«Обычной» сложности за 250–350 дней, пассивная — проигрывает, «Жестокая» требует
аккуратной игры.

## Данные

Границы: [Natural Earth](https://www.naturalearthdata.com/) (public domain) через
`world-atlas`. Население и климатические метрики: пакеты `country-json` и
`world-countries` (ODbL). Всё это уже вкомпилировано в `data/world.js`, игре сеть не нужна.
