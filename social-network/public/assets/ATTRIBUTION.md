# Ассеты

## Шрифты

- `fonts/Inter.ttf`: шрифт Inter, лицензия SIL Open Font License 1.1.
- `fonts/JetBrainsMonoNerdFontMono-Regular.woff2`: JetBrains Mono (Nerd Font, моноширинный вариант), лицензия SIL Open Font License 1.1.

Оба шрифта взяты из репозитория OpenCode (`packages/ui/src/assets/fonts/`), где OpenCode их использует в интерфейсе.

## Изображения и значки сайта OpenCode

Папка `opencode/` содержит файлы из каталога `packages/web` репозитория
<https://github.com/anomalyco/opencode> (ветка `dev`): favicon, иконки для
устройств, `social-share*.png`, `logo-*.svg`, скриншоты лендинга и веб-интерфейса.

Код и ассеты OpenCode распространяются по лицензии MIT, текст лицензии: `opencode/LICENSE.txt`.

Логотипы и скриншоты принадлежат OpenCode (Anomaly). В интерфейсе соцсети они не используются, чтобы
не путать продукты. Файлы лежат в проекте для справки и готовы к использованию, если понадобятся.
