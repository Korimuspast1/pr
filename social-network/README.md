# Виртуальная соцсеть

Простая соцсеть в браузере: регистрация, профиль, лента, посты, лайки, комментарии, подписки и поиск людей.
Подписчики у новых аккаунтов появляются **постепенно**, потому что в сети живут виртуальные боты.

Проект написан на чистом Node.js (22+) и обычном JavaScript. **Внешние npm-пакеты не нужны**, `npm install` не требуется.

## Запуск

```bash
cd social-network
npm start
```

Откройте <http://localhost:3000>. Сервер слушает `0.0.0.0`, поэтому доступен и с других устройств в той же сети.

Тесты:

```bash
npm test
```

## Что умеет

| Раздел | Возможности |
| --- | --- |
| **Аккаунт** | Регистрация (логин, имя, пароль), вход, выход. Пароли хранятся как scrypt-хеш с солью. |
| **Оформление** | Тёмная и светлая тема, шрифты Inter и JetBrains Mono, иконки Lucide (ISC), адаптивная вёрстка с нижними вкладками на телефоне. Без эмодзи. |
| **Профиль** | Имя, «О себе» (до 160 символов), цвет аватара, счётчики постов, подписчиков и подписок. |
| **Лента** | Посты тех, на кого вы подписаны, плюс ваши. Подгрузка по кнопке «Показать ещё». |
| **Обзор** | Все посты соцсети от новых к старым. |
| **Посты** | До 500 символов. Удаление своих постов. |
| **Взаимодействие** | Лайки (переключаются повторным нажатием), комментарии до 300 символов. |
| **Люди** | Поиск по логину и имени, список по популярности, подписка и отписка. |
| **Подписчики** | Списки подписчиков и подписок в профиле. |

## Как работает рост подписчиков

В `server/growth.js` есть 31 виртуальный аккаунт (помечены бейджем **«виртуальный»**). Они:

- публикуют посты на разные темы (примерно 2 поста в минуту на всю сеть при интервале 10 с);
- ставят лайки свежим постам, чаще тем авторам, на которых подписаны;
- подписываются на реальных пользователей.

Новый пользователь сразу подписывается на 3 случайных бота, поэтому лента не пустая.

Число подписчиков у реального аккаунта ограничено «лимитом», который растёт со временем:

```
лимит = 2 + возраст_в_минутах + 3 × число_постов + 1.5 × число_лайков   (но не больше 500)
```

Каждые `GROWTH_INTERVAL_MS` миллисекунд (по умолчанию 10 с) с вероятностью 50 % появляется **один** новый подписчик, если текущее число меньше лимита. Поэтому:

- подписчики приходят по одному и не скачком;
- без постов и лайков лимит растёт примерно на одного подписчика в минуту;
- каждый новый пост и каждый лайк поднимают лимит, и рост продолжается.

Все коэффициенты — в начале `server/growth.js`, их легко подстроить.

| --- | --- | --- |

| `HOST` | `0.0.0.0` | Адрес, на котором слушает сервер |

## API

Все запросы и ответы — JSON. Вход возвращает `token`; его нужно передавать в заголовке `Authorization: Bearer <token>`. Токен хранится в памяти страницы и дополнительно в `localStorage`, если тот доступен. Cookie `sid` тоже выставляется (HttpOnly; `SameSite=None; Secure` на HTTPS), но интерфейс от неё не зависит. Интерфейс работает в iframe на другом домене и в iframe с `sandbox` без `allow-same-origin`. API отдаёт `Access-Control-Allow-Origin: *`, потому что авторизация идёт заголовком, а не cookie.

В iframe с `sandbox` без `allow-same-origin` браузер запрещает хранилище и cookie. Поэтому токен дополнительно сохраняется в `window.name`: он переживает перезагрузку фрейма и сбрасывается при закрытии вкладки или выходе из аккаунта.

| Метод | Путь | Описание |
| --- | --- | --- |
| POST | `/api/auth/register` | `{username, password, displayName?}` |
| POST | `/api/auth/login` | `{username, password}` |
| POST | `/api/auth/logout` | Выход |
| GET | `/api/me` | Текущий пользователь |
| PATCH | `/api/me` | `{displayName?, bio?, avatarColor?}` |
| GET | `/api/feed?before=` | Лента |
| GET | `/api/explore?before=` | Все посты |
| POST | `/api/posts` | `{text}` |
| DELETE | `/api/posts/:id` | Удалить свой пост |
| POST | `/api/posts/:id/like` | Поставить или снять лайк |
| GET | `/api/posts/:id/comments` | Комментарии |
| POST | `/api/posts/:id/comments` | `{text}` |
| GET | `/api/users?q=` | Поиск людей |
| GET | `/api/users/:username` | Профиль и посты |
| GET | `/api/users/:username/followers` | Подписчики |
| GET | `/api/users/:username/following` | Подписки |
| POST / DELETE | `/api/users/:username/follow` | Подписаться / отписаться |

Пагинация: в ответе `nextBefore`. Передайте его в параметр `before`, чтобы получить следующую страницу.

## Ограничения

Это учебный/демо-проект, не готовый продукт:

- Данные хранятся в памяти и сохраняются в JSON-файл. Для большой нагрузки нужна настоящая БД (например, SQLite или PostgreSQL).
- Нет HTTPS, email-подтверждения, восстановления пароля и ограничения частоты запросов.
- Виртуальные аккаунты и их активность — имитация. Это не реальные люди.
- Интерфейс только на русском языке.
