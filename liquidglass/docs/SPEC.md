# ТЗ: Liquid Glass Lab (Android)

Техническое задание на приложение-лабораторию для тестирования материала Liquid Glass
(iOS 26) и на сам материал как переиспользуемый компонент.

Версия 1.0 · Android 13+ (API 33) · без сторонних зависимостей

---

## 1. Цель

1. Дать возможность **щупать** Apple-подобный Liquid Glass на Android: нажимать,
   тянуть, менять фон, переключать варианты.
2. Дать возможность **настраивать** материал вживую: все параметры оптики доступны
   слайдерами, изменения применяются сразу ко всем элементам.
3. Зафиксировать **воспроизводимую спецификацию** материала (оптическая модель +
   числа), чтобы эффект можно было повторить в другом проекте, а не «подобрать на глаз».
4. Показать **референсы** и объяснить, что именно отличает Liquid Glass от обычного
   frosted glass.

## 2. Область работ

Входит:

* движок материала (AGSL-шейдер + RenderNode-пайплайн);
* библиотека компонентов: кнопка-капсула, круглая кнопка, тулбар, таб-бар,
  слайдер, тумблер, меню, карточка/панель, строка списка;
* экран-лаборатория с пресетами, сценами и тюнингом;
* документация (референсы, как повторить, это ТЗ);
* CI-сборка APK и оффлайн-верификация шейдера.

Не входит:

* воспроизведение приватного API Apple (используется только публично описанное
  поведение и открытые разборы);
* темы оформления приложения, магазинные требования, аналитика;
* поддержка API < 33 в полноценном виде (только fallback-заглушка).

## 3. Термины

| Термин | Значение |
|---|---|
| **Backdrop** | всё, что нарисовано под стеклом, в координатах окна |
| **Bevel** | ширина преломляющей кромки |
| **Lens** | амплитуда смещения сэмпла на кромке |
| **Chroma / dispersion** | расщепление RGB на кромке |
| **Regular / Clear** | два варианта материала |
| **Press bulge** | локальное утолщение линзы под пальцем |
| **Materialization** | появление через рост линзы/блика, а не через fade |

## 6. Дизайн-токены (дефолт)

```
bevel 14dp · lens 16dp · lensProfile 0.55 · depth 0 · chroma 0.10
blur 10dp · saturation 1.55 · tint #FFFFFF @ 6% · opacity 1.0
highlight 1.0 · highlightWidth 1.1dp · highlightFalloff 1.0 · lightAngle 225°
innerShadow 0.30 · shadow 12dp @ 18% · grain 1.0 · pressBulge 10dp · pressScale 1.03
Clear: opacity 0.62 · tint ≈ 0 · highlight 1.35 · blur 4dp · dim 35%
```

## 7. Критерии приёмки

1. На сцене «Сетка» и «Текст» под кромкой видно **искривление** линий/букв.
2. На сцене «Светлая» материал не превращается в белую плашку, глифы читаемы.
3. Переключение Regular → Clear меняет прозрачность и добавляет затемнение.
4. Движение слайдера `lens` от 0 до 40 меняет материал без «залипаний» и без пересборки шейдера.
5. Таб-бар: перетаскивание пальцем ведёт пилюлю, отпускание — доводит с пружиной.
6. Меню открывается/закрывается, строка под пальцем подсвечивается.
7. `tools/verify_shader.py` → `OK`; `tools/sync_shader.py --check` → in sync.
8. CI-воркфлоу зелёный, в артефактах есть подписанный APK, `apksigner verify` → `Verifies`.
9. Приложение не падает при выключенном `RuntimeShader` (эмуляция API 31/32 — fallback).
10. Один блюр на кадр: сцена с 8 стеклянными элементами не вызывает ANR и держит
    интерактивность на эмуляторе с software GPU.
11. Снимки экрана на реальном устройстве (эмулятор) приложены в `docs/img/device/`.

## 8. Риски и решения

| Риск | Решение |
|---|---|
| Разные GPU по-разному интерпретируют `exp/sqrt` на больших координатах | все расчёты в локальных координатах элемента, `max()` на знаменателях |
| `setShadowLayer` не работает на hardware canvas в некоторых случаях | тень рисуется отдельным path с `Paint.setShadowLayer`, при отказе — просто нет тени |
| Blur дорогой на слабых GPU | `blur` — параметр, в пресетах «Minimal»/«Clear» снижен |
| Шейдер может не скомпилироваться на конкретном драйвере | `GlassRender.shader()` ловит исключение и отдаёт fallback-путь |
| Ошибки в портах: «радуга», «стекло на стекле» | зафиксировано в `REFERENCES.md` §5 и в чек-листе |
