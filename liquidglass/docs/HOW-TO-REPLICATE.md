## 1. Архитектура: три слоя

```
┌───────────────────────────────────────────────┐
│  Слой 3. Жесты / анимация / доступность        │
│  ─────────────────────────────────────────    │
│  Слой 2. ФУНКЦИОНАЛЬНЫЙ СЛОЙ: стекло          │  ← Liquid Glass живёт ТОЛЬКО здесь
│    таб-бар, тулбар, меню, кнопки, контролы     │
│  ─────────────────────────────────────────    │
│  Слой 1. КОНТЕНТ: фон, картинки, текст, списки │  ← никогда не стекло
└───────────────────────────────────────────────┘
```

Ключевое следствие для реализации: **backdrop снимается один раз на весь экран**, а не
у каждого элемента свой. Иначе элемент, стоящий над другим стеклянным элементом, будет
«сэмплировать стекло», и материал развалится.

В Android это делается так (`GlassRender.java`):

```
sceneNode      = RenderNode(вся сцена: обои + контент)
backdropNode   = RenderNode(sceneNode) + RenderEffect(blur) + ColorMatrix(saturation)
elementNode[i] = RenderNode(backdropNode со сдвигом)  + RenderEffect(runtimeShader)
```

Аналог в iOS: `GlassEffectContainer` — общая область сэмплирования, внутри которой
элементы могут сливаться (smooth-min) и перетекать друг в друга.

## 2. Оптическая модель

### 2.1 Силуэт

Скруглённый прямоугольник с *разными радиусами по углам* (капсула = r = h/2).
Для «яблочного» ощущения скругления берутся суперэллиптические: контрольные точки
кубической кривой на 0.55r вместо 0.42r (`GlassRender.buildSilhouette`).

Из силуэта строится SDF (signed distance field) — это даёт одновременно:

* нормаль к кромке `grad = normalize(∇SDF)`;
* расстояние до кромки `distIn = -SDF` — по нему затухает линза и работает AA.

### 2.2 Линза (главный эффект)

Смещение сэмпла вдоль нормали:

```
t    = clamp(distIn / bevel, 0, 1)              # 0 на кромке, 1 на внутренней границе
prof = pow(1 - sqrt(1 - (1-t)²), lensProfile)   # профиль линзы (circleMap)
disp = lens * prof                              # px
color = backdrop(coord + grad * disp)
```

Смысл профиля: у настоящей стеклянной кромки свет ломается сильнее всего у самого края и
почти не ломается в глубине. `lensProfile = 0.55` (squircle) даёт плавный вход, `1.0` —
круговую линзу с более резким «ободком», `>1` — ещё резче.

Толщина материала для больших поверхностей добавляет слабый pull к центру:

```
disp += depth * lens * 0.22 * (1 - t) * (1 - |c|/2)
```

### 2.3 Дисперсия

Три сэмпла с разным смещением:

```
k = chroma * 0.12
R = backdrop(coord + grad * disp * (1 + k))
G = backdrop(coord + grad * disp)
B = backdrop(coord + grad * disp * (1 - k))
```

`chroma` 0.05–0.15 — едва заметная радуга на цветных объектах; 0.3–0.6 — «линза»,
заметно; > 0.7 — уже аттракцион.

### 2.4 Кромка

```
facing = dot(grad, lightDir)                     # lightDir по умолчанию 225° (слева-сверху)
band   = exp(-distIn / highlightWidth)
spec   = pow(max(facing,0), highlightFalloff) * band * highlight
shade  = pow(max(-facing,0), highlightFalloff) * band
col   += spec
col   *= 1 - 0.175 * shade                       # противоположная сторона темнее
col   += hairline * 0.07 * highlight             # тонкая светлая линия по всему силуэту
```

Плюс внутренняя тень — «толщина» материала, усиленная книзу:

```
inner = exp(-distIn / (bevel * 0.85))
col  *= 1 - innerShadow * inner * mix(0.30, 1.0, y/height)
```

### 2.5 Зерно

`±1.75 %` монохромного шума. Убирает бандинг на градиентах (особенно на светлых обоях)
и даёт «плёночность». В дефолте включено; для минималистичных пресетов можно выключить.

### 2.6 Тон и прозрачность

```
col = mix(col, tint.rgb, tint.a)     # Regular: белый @ 6 %, Clear: почти 0
out = col * opacity                  # Clear: 0.62
```

Всё в premultiplied alpha, антиалиасинг по SDF — 1 px `smoothstep`.

## 3. Параметры (рецепты)

Дефолт «iOS 26 · Regular» (в `GlassPreset.base()`):

| Параметр | Значение | Диапазон | Зачем |
|---|---|---|---|
| `bevel` | 14 dp | 8–26 | ширина преломляющей кромки |
| `lens` | 16 dp | 8–34 | амплитуда смещения на кромке |
| `lensProfile` | 0.55 | 0.45–1.2 | форма профиля линзы |
| `depth` | 0 | 0–1 | «толщина» для крупных поверхностей |
| `chroma` | 0.10 | 0–0.4 | дисперсия |
| `blur` | 10 dp | 4–26 | размытие backdrop |
| `saturation` | 1.55 | 1.0–2.0 | «сочность» под стеклом |
| `tint` | white @ 6 % | 0–20 % | цвет материала |
| `opacity` | 1.0 | 0.55–1.0 | Clear = 0.62 |
| `highlight` | 1.0 | 0.4–2.0 | яркость кромки |
| `highlightWidth` | 1.1 dp | 0.6–2.0 | толщина кромки |
| `highlightFalloff` | 1.0 | 0.5–4.0 | «сжатость» блика к свету |
| `lightAngle` | 225° | любой | направление света |
| `innerShadow` | 0.30 | 0–0.6 | толщина |
| `shadow` | 12 dp @ 18 % | 0–24 dp | отрыв от контента |
| `grain` | 1.0 | 0–1 | зерно |
| `pressBulge` | 10 dp | 0–24 | капля под пальцем |

Готовые пресеты в приложении (`GlassPreset`):

* **iOS 26 · Regular** — дефолт;
* **Thick slab** — bevel 22, lens 24, depth 0.8, shadow 20 @ 26 % (меню, шторки);
* **Clear** — opacity 0.62, tint ≈ 0, highlight 1.35, blur 4;
* **Frosted (Reduce Transparency)** — blur 26, tint 18 %;
* **Lens / physical** — bevel 26, lens 34, profile 1.0, chroma 0.55;
* **Minimal glass** — bevel 6, lens 4, chroma 0, highlight 0.5.

Для мелких контролов (переключатели, чипы) те же пропорции, но меньше: `bevel ≈ 5 dp`,
`lens ≈ 8 dp`, `blur ≈ 6 dp` — иначе кнопка 32 dp высотой просто исчезнет в рефракции.

## 4. Apple API → Android

| iOS / SwiftUI | смысл | Android в этом репозитории |
|---|---|---|
| `.glassEffect()` (по умолчанию капсула) | материал на вью | `GlassSurfaceView` / `GlassRender.drawGlass` |
| `.glassEffect(in: .rect(cornerRadius: 16))` | явный силуэт | `setCornerRadius(dp)` |
| `.glassEffect(.regular.tint(.blue))` | тонирование | `setTint(Color)` / `GlassParams.tintColor` |
| `.glassEffect(.clear)` | Clear-вариант | `GlassParams.variant = CLEAR` |
| `.interactive()` | реакция на нажатие (скейл, блик) | `pressScale`, `pressBulge`, `animatePress()` |
| `GlassEffectContainer(spacing:)` | общая область сэмплирования | один `GlassRender.Backdrop` на экран |
| `glassEffectID` + `@Namespace` | морф между состояниями | анимация общих параметров (silhouette/scale/press) |
| `.buttonStyle(.glass)` | стеклянная кнопка | `GlassButton` |
| `.scrollEdgeEffect` | размытие контента под баром | `blur` + градиентная маска у бара |
| `UIGlassEffect` (UIKit) | то же для UIKit | `GlassRender` не зависит от вью-системы |
| Reduce Transparency | морознее | `GlassParams.reduceTransparency` |
| Increase Contrast | контрастная обводка | `GlassParams.increaseContrast` |

## 5. Adaptive: Regular / Clear / доступность

### Regular

* тень усиливается, когда под элементом текст (`shadowAlpha` + `innerShadow`);
* тинт и диапазон яркости плавают, чтобы надпись оставалась читаемой;
* стекло и глифы могут независимо переключаться светлый/тёмный по средней яркости фона.

В лаборатории адаптация считается по 5×5 миниатюре backdrop'а
(`AdaptiveLuminance` идея из Kyant0): средняя люма > 0.5 → тёмные глифы, иначе светлые;
тинт и блюр плавно подмешиваются за ~1 с.

### Clear

* `opacity 0.62`, `tint ≈ 0`, `blur 4 dp`;
* обязателен затемняющий слой **35 % чёрного** (HIG) — иначе на ярком фото контент
  под стеклом «съедает» кромку;
* только поверх медиа и только если контент сверху жирный и яркий.

### Доступность

| Настройка | Что делаем |
|---|---|
| Reduce Transparency | blur ×2.2 + 6 dp, тинт ≥ 55 %, блик ×0.6, зерно 0 — материал становится «матовым» |
| Increase Contrast | hairline 1 dp белый 60 % + 0.5 dp чёрный 35 % по силуэту |
| Reduce Motion | без пружин: короткие fade 120–180 мс, без капли под пальцем |

## 6. Анимация

* **Появление** — не fade, а материализация: `lens` и `highlight` от 0 к норме за 240 мс
  `easeOut`; тень появляется последней.
* **Нажатие** — `pressScale ≈ 1.03`, `pressBulge ≈ 10 dp` под точкой касания,
  `highlight ×1.4`. Отпускание — пружина `spring(damping 0.7, stiffness 300)`.
* **Таб-бар** — пилюля едет с пружиной, растягивается по модулю скорости
  (`1 + min(|v| * 0.9, 0.35)`) и сжимается поперёк — эффект «капли».
* **Меню** — раскрывается из точки нажатия: масштаб 0.92 → 1, прозрачность 0 → 1,
  одновременно растёт `lens` (материализация, а не fade).
* **Морф** — при переходе между состояниями меняются не картинки, а параметры силуэта
  (радиусы, размеры, позиции), поэтому «свет» перетекает по кромке непрерывно.

## 7. Производительность

* backdrop — один `RenderNode` + один blur на кадр; элементы делят его, а не блюрят каждый своё;
* `RuntimeShader` кэшируется по ключу (`GlassRender.shader`), компиляция — один раз;
* `setRenderEffect` на `RenderNode` не пересоздаёт текстуры;
* clipped-элементы рисуются без offscreen-слоёв: шейдер работает как `RenderEffect`
  поверх уже записанного display list;
* на 60 fps уходит ~1 draw call на элемент + blur; на слабых GPU уменьшайте `blur`
  (он дороже линзы: blur — это сепарабельный проход, линза — один сэмпл).

## 8. Оффлайн-верификация

Шейдер в `shader/liquid_glass.sksl` — обычный SkSL (AGSL = SkSL + `layout(color)`-юниформы),
поэтому его можно прогнать на CPU через `skia-python` **ещё до сборки на устройство**:

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install skia-python numpy pillow

python3 tools/sync_shader.py          # Shaders.java ← liquid_glass.sksl
python3 tools/verify_shader.py        # компилирует шейдер так, как его видит app
python3 tools/skialab.py              # рендерит эталонные карточки в build/lab/
```

`tools/verify_shader.py` ловит две самые неприятные ошибки: синтаксис AGSL (иначе
приложение молча уйдёт в fallback) и рассинхрон имён юниформов между шейдером и Java.

`tools/skialab.py` рендерит те же сцены, что и приложение: `docs/img/*.png` в этом
репозитории сделаны именно им, поэтому их можно сравнивать с реальным экраном.

## 9. Чек-лист «1:1»

- [ ] под стеклом видно **искажение**, а не только размытие (проверять на сетке/тексте);
- [ ] кромка светится с одной стороны и темнеет с противоположной;
- [ ] у больших поверхностей кромка шире, тень глубже;
- [ ] на нажатие элемент «дышит» и в точке касания появляется капля;
- [ ] таб-бар/меню/кнопки лежат на одной плоскости и не сэмплируют друг друга;
- [ ] на светлом фоне глифы становятся тёмными (и наоборот);
- [ ] Clear поверх яркого фото читается только с затемнением 35 %;
- [ ] Reduce Transparency делает материал матовым, а не просто более тёмным;
- [ ] нет радужного ореола там, где его не должно быть (`chroma` ≤ 0.25);
- [ ] 60 fps на среднем устройстве при 5–8 стеклянных элементах.
