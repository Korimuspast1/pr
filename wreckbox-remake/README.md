# Wreckbox — ремейк

Фан-ремейк браузерной песочницы разрушения [Wreckbox](https://itslamba.itch.io/wreckbox) (ItsLamba).
Всё написано с нуля на чистом JavaScript + Canvas 2D: **без библиотек, без спрайтов, без внешних ассетов** —
материалы, здания, звук и погодные катастрофы генерируются кодом.

## Запуск

```bash
cd wreckbox-remake
npm start          # http://localhost:4173
```

ES-модули не работают с `file://`, поэтому нужен любой статический сервер
(подойдёт и `python3 -m http.server`).

## Что внутри

**Структурная физика, а не скрипты.** Карта — сетка ячеек 460×300. Каждые 100 мс пересчитываются:

1. `recomputeSupport()` — BFS опоры от фундамента/земли: что держится, а что уже оторвалось;
2. `computeSpan()` — «вылет» консоли: сколько боковых шагов от ближайшей опоры до каждой ячейки
   (поэтому подрезанный дом не висит в воздухе, а обламывается по линии отрыва);
3. `solveLoad()` — передача веса сверху вниз: масса ячейки плюс всё, что на ней лежит, делится на
   несущую способность материала; перегруз копит трещины и рассыпает ячейку в обломки;
4. `applySpanStress()` — слишком длинная консоль ломается, кусок теряет опору и падает;
5. `stepFalling()` — обломки падают по сетке, при приземлении получают урон от высоты падения,
   уминаются в кучу и дробятся дальше (поэтому «складывается внутрь себя» получается само).

Тяжёлые части не проваливаются сквозь лёгкие: ячейка падает только в пустоту или в воду.

**Катастрофы:** динамит, шар-баба, профессиональный снос с зарядами на несущих узлах, ядерная бомба
(1…50 Мт: вспышка, ударная волна, огненный шторм, гриб, тени на стенах через ray-march маску,
радиоактивные осадки), землетрясение, торнадо, цунами, метеоритный дождь, молнии, чёрная дыра.

**Карты:**

| Карта | Что есть |
| --- | --- |
| Город | панельные и монолитные towers, кирпичные и газобетонные дома, метро под улицей, подземный гараж, ЛЭП, фонари, машины, деревья |
| Военная база | бункер с вентиляцией и свинцовой защитой, склад боеприпасов (детонирует), техника, радар и зенитки, которые сбивают ракеты и мелкие метеориты |
| Атомград | реактор в разрезе, градирня, машинный зал, городок атомщиков, убежище с вентиляцией |

**Люди** — тряпичные куклы на verlet-скелете: ходят, паникуют и бегут от опасности, ломаются от
энергии удара, горят, получают радиацию (ослабляется бетоном и свинцом над головой), гибнут от падений.

**Звук** целиком синтезируется на WebAudio: у каждого материала свой удар (стекло, металл, кирпич,
бетон, дерево, грунт), у взрывов — низкий саб с шумом, есть сирены, радар, счётчик Гейгера и
отдельные шины громкости для взрывов, окружения и сигналов + «режим записи».

## Управление

| | |
| --- | --- |
| ЛКМ | применить инструмент |
| ПКМ / СКМ | панорама |
| Колесо | масштаб (0.1×–1.4×) |
| WASD / стрелки | камера |
| `1`…`0`, `-`, `B`, `M`, `C` | инструменты (кувалда, шар, динамит, снос, бомба, землетрясение, торнадо, цунами, метеорит, молния, дыра, здание, материалы, житель) |
| `H` | скрыть интерфейс |
| `T` | замедление ×0.25 («режим записи») |
| `P` / `Esc` | пауза |
| `R` | новый город |
| `F` | полный экран |
| `~` | консоль в игре |

Консоль (`~`): `boom`, `nuke 20`, `quake`, `tornado`, `tsunami`, `meteor`, `rain`, `wind`, `heal`,
`people 10`, `map base`, `disco`, `about`, `help`.

## Тесты

```bash
npm test
```

- `tests/structure.test.mjs` — башня стоит под собственным весом, рушится при снятии опоры,
  оставляет обломки, висящий блок падает, взрыв разрушает кирпич, бетон над головой ослабляет радиацию.
- `tests/maps.test.mjs` — на всех трёх картах ничего не рушится само, ядерный удар сносит квартал,
  подкоп под домом его обрушивает.

## Структура

```
src/materials.js  22 материала: плотность, прочность, твёрдость, горючесть, защита от радиации, вылет
src/world.js      сетка, солвер опоры/нагрузки/консоли, падение, огонь, радиация, электросеть
src/maps.js       три карты и их застройка
src/citizens.js   тряпичные жители
src/effects.js    частицы, ударные волны, гриб, тени, торнадо, цунами, метеоры
src/game.js       инструменты, снаряды, угрозы, ПВО, осадки
src/render.js     рендер сетки (частичный ImageData), свет, ЛЭП, пост-эффекты
src/audio.js      процедурный звук
src/ui.js         HUD, меню, панели инструментов, встроенная консоль
```

## Отличия от оригинала

Это самостоятельная реализация механик, а не декомпиляция: другой код, другая физика, своя графика
и звук. Название и основные идеи — из оригинальной игры ItsLamba; исходники не использовались.
