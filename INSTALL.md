# Установка плагина Profile Flex (`.ttydyn`) в TikTok You

Плагин локально рисует галочку верификации и любые счётчики (подписчики, лайки, видео)
в твоём профиле TikTok. Видно **только на этом телефоне** — на сервере и у других людей
цифры остаются настоящими.

---

## Шаг 0. Скачай файл плагина

Готовый модуль лежит в репозитории:

**[`release/profile-flex.ttydyn`](release/profile-flex.ttydyn)** → кнопка **Download raw file**.

(Его собирает CI при каждом изменении кода: Actions → `build-ttydyn`. Проверить файл можно
командой `python3 tools/ttydyn.py inspect release/profile-flex.ttydyn`.)

---

## Шаг 1. Положи конфиг и укажи свой аккаунт

Плагин читает настройки из JSON-файла, потому что публичного экрана настроек
у динамических модулей мода нет.

1. Открой файловый менеджер → `Android/data/com.zhiliaoapp.musically/files/`
   (если мод установлен как `com.ss.android.ugc.trill` — соответствующую папку).
2. Скопируй туда [`profile-flex/profile_flex.json`](profile-flex/profile_flex.json).
3. Открой его и впиши **свой** `uniqueId` (это `@username` без собаки) и/или числовой `uid`:

```json
{
  "enabled": true,
  "selfOnly": true,
  "uniqueId": "твой_ник",
  "badge": "personal",
  "followerCount": 1000000,
  "likeCount": 25000000,
  "videoCount": 128
}
```

Файл перечитывается на лету: поменял цифры → закрыл и открыл экран профиля, всё обновилось.
Перезагружать телефон и переустанавливать плагин не нужно.

---

## Шаг 2. (Важно) Сохрани функции самого мода

`.ttydyn` — это **весь динамический код мода**, а не «дополнение» к нему. Если поставить
только наш модуль, TikTok You останется без региона, скачивания и фильтров.
Чтобы этого не было, дай плагину оригинальный код мода — он подхватит его и запустит:

1. Возьми **оригинальный** `.ttydyn` (тот, что стоит у тебя сейчас, или официальный
   `tty-release-…-full_….ttydyn`).
2. Переименуй его в `.zip`, распакуй, достань из архива `classes.dex`.
3. Положи его как
   `Android/data/com.zhiliaoapp.musically/files/profile_flex_base.dex`.

Готово: при старте плагин сначала запустит оригинальный мод, потом поставит свои хуки.
Если файла нет — мод просто останется без своих функций, всё остальное работает.

---

## Шаг 3. Установи плагин

В TikTok You: **Настройки мода → «Установить .ttydyn»** → выбери
`profile-flex.ttydyn` → подтверди → полностью закрой приложение (не свернуть, а завершить
процесс) и открой заново.

Проверка, что модуль поднялся (если есть ПК):

```bash
adb logcat -s ProfileFlex
# ожидаемо:
# I ProfileFlex: config: /storage/emulated/0/Android/data/.../files/profile_flex.json
# I ProfileFlex: original mod started from base dex (876048 bytes)
# I ProfileFlex: installed, hooks: 9
```

---

## Если мод отказывается ставить файл

Это главный барьер, и он не обходится «любым способом»: официальная сборка TikTok You
проверяет **ECDSA-подпись** модуля нативным кодом (`verifySignatureNative`) по публичному
ключу, зашитому в APK. Приватного ключа авторов мода нет ни у кого, кроме них, —
подделать подпись математически нельзя.

Рабочие варианты:

| Вариант | Что нужно | Итог |
| --- | --- | --- |
| **A. Своя сборка мода** | пересобрать APK TikTok You, заменив зашитый публичный ключ на свой (`keys/dev.pub.pem`) | плагин ставится штатно через «Установить .ttydyn» |
| **B. Отключить проверку** | в своей сборке замкнуть `verifySignatureNative` на `true` | то же самое |
| **C. Попросить авторов** | отдать им исходники модуля (`profile-flex/`) — они подпишут своим ключом | официальный путь |
| **D. Без мода вообще** | загрузить тот же код как модуль LSPosed/exteraHook-совместимого фреймворка | нужна отдельная обвязка, кода хуков это не меняет |

Если у тебя сборка из варианта A/B — подпиши модуль своим ключом:

```bash
python3 tools/ttydyn.py keygen --out keys/dev          # один раз
TTY_KEY=keys/dev.key.pem ./profile-flex/build.sh       # сборка + подпись
python3 tools/ttydyn.py verify release/profile-flex.ttydyn --pub keys/dev.pub.pem
```

Публичный ключ `keys/dev.pub.pem` (32 байта X + 32 байта Y, P-256) — это и есть то,
что нужно вшить в свою сборку мода.

## Что делать, если галочка не появилась

1. `adb logcat -s ProfileFlex` — смотри строки `method not found: User.getXxx`.
   Значит, в твоей версии TikTok метод называется иначе: допиши имя в
   `ProfileFlex.install()` (`profile-flex/src/main/java/dev/ttydyn/profileflex/ProfileFlex.java`)
   и пересобери.
2. Проверь, что `uniqueId`/`uid` в конфиге совпадают с профилем (регистр не важен,
   собаку писать не надо). Для быстрой проверки можно временно поставить
   `"selfOnly": false` — тогда подмена применится ко всем профилям.
3. Убедись, что приложение было закрыто полностью, а не свёрнуто.

## И ещё раз, честно

Это **визуальная локальная подмена**: скриншот с ней не доказательство ни для кого,
реальную верификацию, подписчиков или монетизацию она не даёт. Моды TikTok
в принципе повышают риск бана аккаунта — решай сам.
