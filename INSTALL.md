# Установка Profile Flex (`.ttydyn`) в TikTok You

Profile Flex меняет только локальные объекты профиля на устройстве: это не настоящая
верификация и не изменение аккаунта на сервере.

## Важное ограничение подписи

Готовый `release/profile-flex.ttydyn` подписан dev-ключом, публичная часть которого
лежит в `keys/dev.pub.pem`. Он устанавливается в **собственную/debug-сборку TikTok
You**, где этот публичный ключ вшит в APK.

Официальный APK проверяет `signature.der` нативным кодом по своему публичному ключу.
Приватного ключа авторов официальной сборки в репозитории нет, поэтому заменить
подпись так, чтобы официальный APK принял файл, невозможно. Если официальный APK
показывает ошибку подписи — это ожидаемая защита, а не повреждение ZIP.

## 1. Проверить готовый пакет на компьютере

Из корня репозитория:

```bash
python3 tools/ttydyn.py inspect release/profile-flex.ttydyn --classes 20
python3 tools/ttydyn.py verify release/profile-flex.ttydyn --pub keys/dev.pub.pem
unzip -t release/profile-flex.ttydyn
```

Ожидаемый результат:

```text
целостность: OK
подпись: OK
```

Если эти команды не проходят, не пытайтесь переименовывать файл или редактировать
ZIP — скачайте пакет заново или пересоберите его.

## 2. Подготовить конфигурацию

1. Откройте файловый менеджер →
   `Android/data/com.zhiliaoapp.musically/files/`.
2. Скопируйте туда `profile-flex/profile_flex.json`.
3. Укажите свой `uid` и/или `uniqueId` без символа `@`:

```json
{
  "enabled": true,
  "selfOnly": true,
  "uid": "",
  "uniqueId": "твой_ник",
  "badge": "personal",
  "spoofCounters": true,
  "followerCount": 1000000,
  "followingCount": 42,
  "likeCount": 25000000,
  "videoCount": 128
}
```

Если приложение установлено как `com.ss.android.ugc.trill`, используйте каталог с
этим именем. Конфиг перечитывается примерно раз в несколько секунд; после изменения
закройте и снова откройте профиль.

## 3. Установить модуль

1. Запустите TikTok You.
2. Откройте **Настройки мода → Установить .ttydyn**.
3. Выберите `release/profile-flex.ttydyn` и подтвердите импорт.
4. Полностью завершите приложение и откройте его снова.

Проверка запуска:

```bash
adb logcat -s ProfileFlex
```

Полезные строки:

```text
I/ProfileFlex: config: .../profile_flex.json
I/ProfileFlex: installed, hooks: N
```

Отсутствие `profile_flex_base.dex` не является ошибкой: в таком режиме работают
только хуки Profile Flex.

## 4. Сохранить функции исходного мода

`payloadType: full` означает, что `.ttydyn` содержит весь dynamic dex, а не патч.
Перед заменой сохраните оригинальный `.ttydyn`.

Чтобы сначала запустить оригинальный dynamic dex, распакуйте из него `classes.dex` и
положите файл в каталог external files приложения под именем:

```text
profile_flex_base.dex
```

Если файл отсутствует или не подходит версии мода, Profile Flex не должен ронять
приложение: в logcat появится `chain load failed`, после чего установятся собственные
хуки.

## 5. Сборка и подпись

Нужны JDK 17+, Android SDK с `android.jar` и `d8`, Python 3:

```bash
python3 tools/ttydyn.py keygen --out keys/dev  # один раз
./profile-flex/build.sh
python3 tools/ttydyn.py verify release/profile-flex.ttydyn --pub keys/dev.pub.pem
```

Скрипт проверяет соответствие приватного и публичного ключа и не создаёт новый ключ
молча. Если нужна осознанная новая dev-пара:

```bash
TTY_GENERATE_KEY=1 ./profile-flex/build.sh
```

После этого новый `keys/dev.pub.pem` нужно вшить в свою сборку TikTok You. Для
production приватный ключ храните вне Git.

## Если импорт всё ещё не проходит

| Сообщение | Причина и решение |
| --- | --- |
| Ошибка подписи | Публичный ключ APK не совпадает с `keys/dev.pub.pem`; используйте свою сборку мода или подпись авторов. |
| Файл повреждён | Выполните `unzip -t` и `tools/ttydyn.py verify`; скачайте архив заново. |
| Версия ниже установленной | Установщик отклоняет `dynamicVersion`, если пакет старее принятого; пересоберите с большей версией. |
| Модуль импортировался, но хуков 0 | Версия TikTok изменила имена классов/методов; смотрите `adb logcat -s ProfileFlex`. |
| Нет изменений в профиле | Проверьте `uid`/`uniqueId`, `enabled` и что профиль открыт после полного перезапуска. |
| Пропали функции мода | Это ожидаемо для `payloadType: full`; восстановите оригинальный `.ttydyn` или положите его `classes.dex` как `profile_flex_base.dex`. |

Локальная подмена не даёт реальной верификации, подписчиков, монетизации или
доступа к функциям сервера. Использование модифицированных клиентов может привести
к блокировке аккаунта.
