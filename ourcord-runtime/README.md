# OurCord Runtime
The JavaScript/React Native runtime injected by OurCord Loader. It adds an OurCord control center to Discord settings with plugins, themes, fonts, safe mode, developer tools, and update support while preserving Bunny/Vendetta plugin compatibility.

Build with `npm ci && npm run build -- --release-branch main --build-minify`. Licensed under BSD-3-Clause; see `LICENSE` and `UPSTREAM.md`.
