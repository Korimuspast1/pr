# RootDB Pro

Root-редактор локальных баз Android в духе APK Editor Pro: список всех приложений,
сканирование их баз через root, правки, расшифровка и фоновая защита от отката.
Дизайн — **Material Expressive** (Material 3 Expressive + динамический цвет).

## Что умеет

- **Root** (libsu): Magisk / KernelSU / APatch / SuperSU. Без root доступны только свои базы.
- **Все приложения**: список с иконками, поиском и фильтрами (пользовательские/системные).
- **Сканер баз**: `databases/`, `files/`, `cache/` — SQLite по заголовку файла,
  пометки WAL/SHM/JOURNAL и «похоже на SQLCipher».
- **Редактор таблиц**: просмотр строк с пагинацией, поиск по значениям, правка ячеек,
  добавление/удаление строк, экспорт CSV/JSON. Правки пишутся обратно через root
  с исходными правами и владельцем файла.
- **SQL-консоль**: любой запрос, результат таблицей.
- **Глобальный поиск**: значение по всем базам и таблицам приложения.
- **Расшифровка**: SQLCipher → обычная SQLite (пароль или hex-ключ) и обратно;
  декодеры значений (Base64/Hex/URL/JSON/Unicode) + AES-CBC/ECB.
- **SharedPreferences**: просмотр и правка XML через root.
- **Файлы**: root-браузер каталога данных приложения, просмотр текста/hex.
- **Бэкапы**: копии баз с восстановлением в один тап.
- **Guardian**: фоновая служба (foreground, dataSync) следит за изменёнными базами
  и не даёт приложению откатить правки: восстановление из бэкапа, force-stop
  или только уведомление. Лог событий, настройка интервала, исключение из
  оптимизации батареи.

## Сборка

Требуется JDK 17 и Android SDK (platform 34, build-tools 34.0.0).

```bash
cd rootdb-editor
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

В CI APK собирается автоматически (`.github/workflows/build-rootdb.yml`):
артефакт на каждый push, GitHub Release — при ручном запуске workflow.

## Установка

1. Установите APK на устройство с root.
2. Откройте приложение → «Запросить root» → разрешите в Magisk/KernelSU.
3. Выберите приложение → база → правьте. После сохранения приложение
   останавливается (настройка), чтобы не перезаписать правки.
4. Для защиты от отката включите Guardian на экране базы.

> Используйте только на своём устройстве и для своих данных.
