# VOID // НЕВОЗМОЖНЫЙ ЯЗЫК

> **Напиши невозможное. Запусти неизбежное.**

**VOID** — наш собственный язык программирования. Полностью с нуля. Без чужих фреймворков, без зависимостей, без npm/pip install. Только чистый Python как носитель, а внутри — своя вселенная.

```
         ⌀  V O I D  ⌀
     язык уровня невозможности
     на котором возможно писать
```

---

### Почему "уровень невозможности" ?

Обычные языки говорят компьютеру **ЧТО делать**. VOID говорит реальности **ЧЕГО НЕ МОЖЕТ БЫТЬ** — и заставляет это случиться.

1. **Парадокс как тип данных.** Переменная может быть `42` и `!= 42` одновременно. Вычисляется только в момент `коллапса`.
2. **Память-бездна.** Переменные исчезают, если их не `закрепить`. Забыл — вселенная забыла.
3. **Время — первоклассный объект.** Функция может вызвать себя *до* своего определения. Петля может идти назад.
4. **Отрицание реальности.** Оператор `~` не просто `not`, а инверсия смысла.
5. **Двуязычие.** Пиши как хочешь: `призвать` или `summon`, `если` или `if`, `эхо` или `echo`. Это НАШ язык.

И при этом — **писать легко**. Синтаксис чистый, читаемый, без боли Brainfuck'а.

### Пример: Привет, Бездна

```void
# hello.void — твое первое невозможное
бездна main {
    эхо "Привет, невозможность! ⌀";
    эхо "Это VOID. Наш язык. С нуля.";
    
    связать x = 42;
    эхо "x = " + x;
}
```

### Пример: Парадокс

```void
# paradox.void — переменная которая не должна существовать
бездна main {
    # парадокс: значение вычисляется только когда на него смотрят
    парадокс p => 10 / 0 ?! 42;

    эхо "p до коллапса: " + p;     # еще не вычислено
    коллапс p -> y;                # теперь 42, потому что деление на 0 невозможно -> сработал план Б
    эхо "p после коллапса: " + y;
}
```

### Пример: Фибоначчи сквозь время

```void
призвать фиб(n) {
    если n <= 1 { вернуть n; }
    вернуть фиб(n-1) + фиб(n-2);
}

бездна main {
    для i в 0..10 {
        эхо фиб(i);
    }
}
```

### Философия VOID

| Обычные языки | VOID |
|---|---|
| Переменная хранит значение | Переменная хранит *возможность* значения |
| Ошибка = краш | Ошибка = ветвление реальности (`?!`) |
| Функция вызывается после определения | Функция существует всегда, определение — лишь наблюдение |
| `null` — отсутствие значения | `пустота` — присутствие отсутствия |
| Комментарий игнорируется | `шепот` — комментарий который может стать кодом |

**VOID — это не про удобство. VOID — это про власть писать то, чего не может быть.**
