# МАНИФЕСТ VOID

> **Мы не взяли чужой язык. Мы родили свой.**

Каждый язык программирования — это договор с реальностью.
Python договорился быть простым. C договорился быть быстрым. JavaScript договорился быть везде.

**VOID договорился быть невозможным.**

---

### Что значит "наш" ?

* **Наш** — значит без `pip install`. Без `npm`. Без 2 ГБ `node_modules`. Один файл `void.py` — и всё работает.
* **Наш** — значит ты можешь писать `призвать` вместо `function`, `эхо` вместо `print`, `пустота` вместо `null`. Твой язык знает твой язык.
* **Наш** — значит мы сами решаем, что такое `истина`.

### Что значит "с нуля" ?

* Лексер написан руками. Регулярка — единственная роскошь.
* Парсер — рекурсивный спуск, без yacc, без ANTLR.
* Интерпретатор — обход AST, без LLVM, без байткода.
* 0 зависимостей. 0 импортов кроме `sys, re, time, random, math`.

Ты можешь прочитать ВЕСЬ язык за один вечер.

### Что значит "уровень невозможности" ?

В обычных языках ошибка — это провал. В VOID ошибка — это **ветвление реальности**.

```
связать x = (10 / 0) ?! 42;
```

В Python — `ZeroDivisionError`. В VOID — `x = 42`. Потому что если одна реальность невозможна — мы берём другую.

Переменная может не существовать до тех пор, пока ты на неё не посмотришь. Функция может быть вызвана до того, как определена. Время в VOID не стрелка, а кольцо.

И при этом — **на нём можно писать**. Не как на Brainfuck, где чтобы вывести "Hello" нужно 100 символов. На VOID пишешь почти как на псевдокоде, но с привкусом бездны.

---

### Зачем ?

Потому что можем.

Потому что "невозможно" — это самое интересное слово в программировании.

**VOID — это не язык для продакшена. VOID — это язык для ощущения власти.**

Ты пишешь невозможное. Оно компилируется. Оно работает.

Что может быть круче ?
