# VOID — Спецификация языка v0.1 "Невозможность"

## 1. Виды токенов

### Комментарии
```
# обычный комментарий до конца строки
шепот "это тоже комментарий, но в стиле VOID"
```

### Литералы
```
42          # число (int/float)
3.14
"строка"    # строка в двойных кавычках, с экранированием \n \t \" \\
пустота     # null / void — единственное значение типа void
истина      # true
ложь        # false
```

## 2. Грамматика (упрощенная EBNF)

```
program     ::= statement*
statement   ::= varDecl | funcDecl | abyssBlock | ifStmt | whileStmt | loopStmt | forStmt
              | echoStmt | returnStmt | collapseStmt | breakStmt | continueStmt
              | exprStmt | whisperStmt

varDecl     ::= ("связать" | "bind" | "let") IDENT ("=" expr)? ";"
              | ("парадокс" | "paradox") IDENT "=>" expr ";"

funcDecl    ::= ("призвать" | "summon") IDENT "(" params? ")" block

abyssBlock  ::= ("бездна" | "abyss") IDENT? block

ifStmt      ::= ("если" | "if") expr block (("иначе" | "else") block)?

whileStmt   ::= ("пока" | "while") expr block
loopStmt    ::= ("петля" | "loop") block
forStmt     ::= ("для" | "for") IDENT ("в" | "in") expr block

echoStmt    ::= ("эхо" | "echo" | "print") expr ";"
returnStmt  ::= ("вернуть" | "return") expr? ";"
collapseStmt::= ("коллапс" | "collapse") expr ("->" IDENT)? ";"
whisperStmt ::= ("шепот" | "whisper") STRING ";"

block       ::= "{" statement* "}"

expr        ::= paradoxChoice
paradoxChoice ::= orExpr ("?!" orExpr)*
orExpr      ::= andExpr (("или" | "||" | "or") andExpr)*
andExpr     ::= equality (("и" | "&&" | "and") equality)*
equality    ::= comparison (("==" | "!=") comparison)*
comparison  ::= term (("<" | ">" | "<=" | ">=") term)*
term        ::= factor (("+" | "-") factor)*
factor      ::= unary (("*" | "/" | "%") unary)*
unary       ::= ("!" | "~" | "не" | "-")* primary
primary     ::= NUMBER | STRING | "пустота" | "void" | "истина" | "true" | "ложь" | "false"
              | IDENT ("(" args? ")")?
              | "(" expr ")"
              | "[" (expr ("," expr)*)? "]"   # массив
              | rangeExpr
rangeExpr   ::= expr ".." expr

params      ::= IDENT ("," IDENT)*
args        ::= expr ("," expr)*
```

## 3. Семантика невозможности

### 3.1 Тип `пустота`
Единственное значение. Равно ничему и всему одновременно в слабом сравнении. `пустота + 5 = 5`, `пустота == ложь == 0 == ""`.

### 3.2 Парадокс `=>` и `?!`
```void
парадокс p => 10 / 0;       # не вычисляется сразу, хранится как thunk
коллапс p -> v;             # форсирует вычисление, v = ошибка? тогда пустота
связать a = (10 / 0) ?! 42; # если слева ошибка/пустота/ложь-как-ошибка -> взять право
```
Оператор `?!` — сердце языка. "Если невозможное случилось — возьми запасную реальность".

### 3.3 Переменные-исчезновения
Обычная `связать x = 5;` живет вечно в своей области. Но `парадокс` без `закрепить` может "испариться" если на него долго не смотреть (в данной версии — живет, но в будущем — будет TTL).

### 3.4 Области видимости
Лексическая. Каждый `{}` — новая область. Замыкания работают.

## 4. Встроенные функции

```
длина(arrOrStr) / len(...)
строка(x) / str(x)
число(s) / num(s)
тип(x) / type(x)
время() / time()         # секунды с запуска
случайно() / random()    # 0..1
```

## 5. Расширения будущего (заявка на невозможность)

- `время вспять { ... }` — выполнить блок задом наперед
- `наблюдать x { ... }` — квантовый наблюдатель
- `законы { гравитация = 0 }` — переопределение семантики операторов
- Компиляция в байткод бездны `.voidx`
