# DeepSeek V3 Studio

Локальный веб-интерфейс для DeepSeek V3 с безопасным серверным прокси к OpenAI-compatible API.

## Запуск

```bash
npm start
```

Откройте `http://localhost:4173`.

По умолчанию приложение запускается в **демо-режиме**: интерфейс полностью доступен, но запросы не уходят во внешний сервис. Чтобы подключить реальную модель, создайте `.env` на основе `.env.example` и добавьте ключ платформы DeepSeek:

```bash
cp .env.example .env
# впишите DEEPSEEK_API_KEY=sk-...
npm start
```

Ключ читается только Node-сервером и не попадает в браузер. Модель по умолчанию — `deepseek-chat`; её можно переопределить через `DEEPSEEK_MODEL`.

## Важно о локальном запуске самой модели

Оригинальный DeepSeek-V3 — MoE-модель на 671B параметров (37B активных на токен). Её официальный локальный inference рассчитан на Linux и многокарточные конфигурации; загрузка весов на обычной машине не является реалистичным вариантом. Поэтому этот интерфейс использует официальный DeepSeek API либо любой совместимый серверный endpoint через адаптацию в `server.mjs`.
