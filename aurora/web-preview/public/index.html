Кликните по экрану, чтобы передать клавиатуру и мышь в ОС.

Это не макет интерфейса

Экран ниже — настоящий вывод ядра Aurora, запущенного в QEMU на сервере. Браузер получает кадр по VNC/WebSocket и отправляет обратно события клавиатуры и мыши. Команды выполняются внутри самой ОС, а не в JavaScript-имитации.

  • Кликните по экрану и введите help в Terminal.
  • Попробуйте mem, uptime, windows, new, monitor.
  • Перетащите окно за заголовок — это делает оконный менеджер ядра.
  • fault-test вызывает настоящий page fault и экран паники.
  • reboot перезагружает ОС; кнопка «Перезагрузить ВМ» делает аппаратный сброс через QEMU.
  • halt останавливает CPU. После этого нажмите «Перезагрузить ВМ».

Что запущено

        
Aurora 1.0.0, x86-64, C + ассемблер, Limine BIOS. Текущий сеанс — BIOS-загрузка.

      

      

        
Что настоящее

        
Ядро, драйверы PS/2, PIT, PIC, рамочный буфер, оконный менеджер и shell выполняются в ВМ.

      

      

        
Ограничения

        
Учебная live-ОС: без сети, USB-стека и установки на диск. Один общий сеанс; ваши действия видят все зрители.
