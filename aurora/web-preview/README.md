# Aurora OS — живой веб-preview

Это не HTML-макет рабочего стола. Сайт запускает настоящий `aurora.iso` в QEMU
(x86-64, 512 МБ RAM, BIOS) и транслирует кадр гостевой ОС в браузер через
VNC/WebSocket. Клавиатура и мышь из браузера передаются обратно в ВМ.

## Запуск

Нужны Node.js 18+, QEMU с поддержкой x86-64 и VNC, а также собранный ISO.

```bash
cd aurora/web-preview
npm ci
QEMU_BIN=qemu-system-x86_64 AURORA_ISO=../dist/aurora.iso npm start
```

Откройте `http://localhost:8080`.

Переменные окружения:

- `PORT` — HTTP-порт сайта, по умолчанию `8080`;
- `QEMU_BIN` — путь к `qemu-system-x86_64` или обёртке;
- `AURORA_ISO` — путь к ISO, по умолчанию `../dist/aurora.iso`;
- `VNC_PORT` — внутренний VNC-порт QEMU, по умолчанию `5901`.

VNC слушает только `127.0.0.1`; наружу публикуется только HTTP/WebSocket сайт.
Сеанс общий: все зрители видят одну и ту же ВМ и могут управлять ею.

## Проверка

```bash
node tests/rfb-smoke.mjs
```

Тест проверяет HTTP-статус, RFB-рукопожатие, ввод `help` с клавиатуры и
перетаскивание окна мышью через настоящий VNC-поток.

## Производительность

В 1.0.1 курсор обновляется отдельным маленьким прямоугольником, а перетаскивание
окна передаёт только повреждённую область. VNC-прокси ограничивает очередь для
медленных клиентов (backpressure). Это остаётся настоящим выводом ядра Aurora,
а не клиентской имитацией интерфейса.
