# 2D Sandbox (People Playground / GoreBox style)

Песочница с видом сбоку: процедурная карта, управляемый персонаж, физика
рэгдолла, кровь и лужи. Пока без оружия — панель инструментов снизу пустая,
её будем наполнять дальше.

## Запуск

```bash
cd game
python3 -m http.server 8080
# открыть http://localhost:8080
```

Или просто открыть `game/index.html` в браузере — зависимостей нет,
всё на чистом Canvas 2D.

## Управление

| Клавиши | Действие |
| --- | --- |
| `A` / `D` или `←` / `→` | идти |
| `Shift` | бег |
| `Space` / `W` / `↑` | прыжок |
| `ЛКМ` по персонажу | схватить и швырнуть (как в People Playground) |
| колесо мыши | зум |
| `F1` | показать скелет и отладку |

## Что уже есть

- **Карта**: рельеф 6800 px с холмами, ямой, травой, деревьями, параллаксом
  (4 слоя холмов), облаками, солнцем.
- **Персонаж**: кинематический скелет с IK-ногами, походка с шагами
  «планта-свинг», наклон корпуса, махи руками, прыжки с приземлением.
- **Физика** (`js/physics.js`): Verlet-интегратор, жёсткие кости, ограничители
  суставов, трение и нормальная реакция на склоне рельефа, столкновения точек
  разных тел, «рука» для захвата мышью с ограничением силы.
- **Рэгдолл**: при сильном ударе или захвате персонаж обмякает, падает,
  а потом сам поднимается, если жив.
- **Кровь**: брызги с баллистикой, капли оставляют лужи на земле, персонаж
  постепенно покрывается кровью, при смерти — крестик вместо глаза и
  оторванная рука.
- **Здоровье**: урон от удара, от падения с высоты; полоска над головой и HUD.

## Структура

```
game/
  index.html      разметка, HUD, нижняя панель инструментов (10 пустых слотов)
  style.css       интерфейс
  js/terrain.js   рельеф (шум, сглаживание, высота/наклон)
  js/physics.js   Verlet-мир: точки, кости, суставы, рельеф, захват
  js/human.js     персонаж: поза, IK, походка, урон, рэгдолл, отрисовка
  js/effects.js   кровь, брызги, пыль, лужи
  js/render.js    небо, параллакс, рельеф, деревья, трава
  js/main.js      игровой цикл, ввод, камера, HUD
  test/           headless-проверки физики и цикла
```

## Тесты

```bash
cd game
node test/sim.js             # физика персонажа: стойка, ходьба, урон, смерть
node test/browser-smoke.js   # прогон игрового цикла на стабах canvas/DOM
```
