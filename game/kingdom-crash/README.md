# Kingdom Crash 2.0

Пиксельная средневековая стратегия для Android. Работает без интернета, ничего не отправляет и не
требует разрешений.

## Состав

| Папка | Что внутри |
|---|---|
| `www/` | сама игра: `index.html`, `style.css`, `font.css`, `img/`, `js/` |
| `android/` | оболочка приложения и сборка APK (`android/README.md`) |
| `tools/` | проверки: логика, партии ботов, сценарии в браузере, статический анализ |
| `release/` | готовый APK |

Скрипты игры (`www/js`), в порядке подключения:

| Файл | Назначение |
|---|---|
| `boot.js` | экран сбоя, если игра не запустилась |
| `data.js` | таблицы: здания, отряды, державы, события, значки, спрайты |
| `map.js` | создание карты |
| `game.js` | правила игры, сохранение и загрузка |
| `ai.js` | соперники |
| `render.js` | отрисовка карты, управление пальцем |
| `audio.js` | звуки и музыка (синтезируются, файлов нет) |
| `ui.js` | интерфейс: панели, окна, письма, меню, награды, рекорды, настройки |
| `main.js` | запуск и главный цикл |

## Что изменилось по сравнению с версией 1

**Исправлено**

- столицы могли появиться вплотную друг к другу, две державы — получить один цвет;
- производство сжигало сырьё при полном складе; смена изделия теряла вложенное;
- торговля продолжалась с уничтоженными державами; на письма можно было ответить после срока;
- погибшие бойцы оставались на карте, отступление «залипало», армия могла появиться в воде или в стене;
- при поражении победителем объявлялся игрок; песочница без соперников зависала;
- пауза сбрасывалась или залипала после окна писем;
- после «Продолжить» игра проматывала время, автосохранение переставало работать, приветствие дублировалось;
- повреждённое сохранение роняло игру — теперь оно проверяется целиком и даёт понятное сообщение;
- сбой записи сохранения проходил молча;
- сбой в одном кадре останавливал игру навсегда;
- в шрифте не было части знаков (звёздочки, галочки, кавычки) — вместо них стояли пустые квадраты;
- запуск замирал на несколько секунд, пока просчитывался фон меню;
- два полноэкранных прохода в каждом кадре съедали до двух третей времени отрисовки.

**Защита**

- страница закрыта политикой CSP: никаких сетевых запросов, встроенных скриптов и `eval`;
- все имена и тексты из сохранения выводятся как текст, а не как разметка;
- у приложения нет разрешений; WebView не видит файлы телефона и не может уйти со страницы игры.

**Новое**

- каменный интерфейс: камень, дерево, пергамент, железо;
- мельница (+50% еды соседним фермам) и таверна (наёмники за золото);
- ополчение и копейщики, изделие «копья»;
- у каждой из 8 держав — своя особенность;
- вольные города, 10 случайных событий (два — с выбором);
- соперники умнее: ультиматумы, ополчение, мельницы, таверны, объединение армий;
- 25 наград, таблица рекордов, настройки;
- звуки и музыка (лютня);
- кнопка «Назад», сохранение при сворачивании.

## Проверки

```sh
node tools/test_logic.js               # правила игры: 4389 проверок
node tools/sim.js www/js 24 24000      # 24 партии ботов с проверкой целостности мира
sh tools/lint.sh                       # статический анализ (нужен eslint 8)
node tools/flows.js                    # сценарии в браузере (нужен playwright)
node tools/shots.js                    # снимки всех экранов
node tools/sizes.js                    # раскладка на разных экранах
```

Для браузерных проверок: `npm i playwright@1.49.1 eslint@8.57.0` в любой папке и
`KC_TOOLS=<эта папка>` в окружении.

## Сборка

```sh
sh android/build.sh
```

Подробности — в `android/README.md`.
