# Скриншоты рендера 2.9.0 (мягкая графика)

Рендеры кадра игровым движком (tools/ui_shot.js, @napi-rs/canvas, seed 4242):

- `before/` — до правок (только зерно убрано, UI без мягкого света);
- `after/` — после: кубика Кэтмулла-Рома вместо ступенчатого лерпа полей
  (трава, вода, рельеф без «террас»), скруглённые края и размытые тени в UI,
  виньетка, тёплое свечение окон городов ночью, светлячки в сумерки,
  мягкие тени облаков и овалы-тени под зданиями.

Файлы: `spring_rain.png` (утро, дождь), `fest_close_day.png` (ночь, праздник,
свечение города), `winter_snow_cart.png` (день, караван).

Особенность снимков: инструмент строит кадры по одному, а игра достраивает
участки карты лениво (3 участка за кадр). Поэтому на снимке видны ровные
заливные клетки там, где участок ещё не успел построиться (у воды это выглядит
синими «пунктирными» границами — цвета TCOL из render.js). В живой игре они
исчезают через долю секунды после загрузки и не являются багом.
