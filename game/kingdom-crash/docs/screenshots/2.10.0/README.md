# Скриншоты 2.10.0

- `icon_contact_sheet.png` — полный набор векторных SVG-иконок (57 штук),
  отрисован через @resvg/resvg-js на тёмной подложке. Размер рендера 24×24,
  стиль: плоские заливки + тёмный контур, единые «фирменные» цвета
  (золото #f2c230, дерево #a06a35, сталь #b8c4d4 и т.д.).

Иконки вшиты в код как inline-SVG (`SV` в js/data.js, `IMG()` отдаёт `<svg>`),
поэтому на любом масштабе и в любом WebView они чёткие без растеризации.
