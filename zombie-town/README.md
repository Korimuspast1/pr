# 🏘️🧟 Cozy Pixel Zombie Town

Пиксельный 2D градостроительный симулятор выживания для Android. Город **сам заселяется и растёт** — люди приходят с края карты, строят домики, многоэтажки и небоскрёбы. А зомби спавнишь **ты, в любой момент** — одной кнопкой.

## 🎮 Как играть

- **Город живёт сам**: переселенцы приходят, если есть жильё, еда, вода и счастье. Строители сами возводят дома; полные дома растут в многоэтажки, а те — в небоскрёбы.
- **Жители адаптируются**: у них есть потребности (еда, вода, сон), профессии (строитель, фермер, охранник, медик…), опыт. Когда рядом зомби — они **крадутся медленно**, чтобы их не заметили, **прячутся в домах** или бегут в убежище. Загнанные в угол — дерутся.
- **Зомби ищут людей**: они видят жителей (крадущихся — хуже), слышат шум (стройку, выстрелы, тревогу), идут на последний след и проверяют дома. Ночью они агрессивнее.
- **Спавн зомби — когда захочешь**: кнопка 🧟 внизу экрана: ×1, ×5, орда ×20 или полная вспышка с волнами. Точки спавна: край карты, лес, гнездо.
- **Защита**: стены, ворота, башни, турели, шипы, убежище, кнопка тревоги 🚨.
- **После атаки**: ремонтируй и перестраивай здания, лечи заражённых в клинике, хорони погибших на кладбище.
- **Управление**: перетаскивание — панорама, щипок — масштаб, тап — выбрать, долгое нажатие — инфо. Скорость игры 1×/2×/4×, пауза.
- **Сохранения**: автосейв каждые 2 минуты + 3 ручных слота. Работает офлайн, без интернета и разрешений.

## 🛠 Технологии

- HTML5 Canvas + чистый JavaScript (без сборки и зависимостей в рантайме)
- Android-обёртка: **Capacitor** (WebView), landscape, minSdk 24
- Пиксель-арт и звук генерируются процедурно в коде — никаких чужих ассетов
- Путь: BFS по сетке + поиск по полям; пулы объектов для частиц/снарядов
- Сборка APK — автоматически в **GitHub Actions** (см. `.github/workflows/build-apk.yml`)

## 📁 Структура

```
zombie-town/
  www/                  # игра (открывается прямо в браузере)
    index.html
    css/style.css
    js/
      config.js         # данные: здания, ресурсы, профессии, зомби, i18n
      sprites.js        # процедурный пиксель-арт
      map.js            # генерация карты, сетка, поиск пути
      entities.js       # жители (стелс/опыт) и зомби (поиск/шум)
      buildings.js      # здания: стройка, ремонт, улучшения, руины
      audio.js          # процедурный звук и музыка (WebAudio)
      save.js           # JSON-сейвы с версионированием
      ui.js             # HUD, меню, панели
      game.js           # менеджеры, цикл, камера, авто-рост города
  android/              # Android-проект (Capacitor)
  test/smoke.js         # headless-тест игровой логики (node)
```

## ▶ Запуск в браузере

```bash
cd zombie-town
npx serve www -l 8080   # или: python3 -m http.server 8080 -d www
# открыть http://localhost:8080
```

## 📱 Сборка APK

Локально (нужны JDK 17 и Android SDK):

```bash
cd zombie-town
npm install
npx cap sync
cd android && ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Или просто запушить в GitHub — workflow `Build Zombie Town APK` соберёт APK автоматически и приложит его как артефакт. Готовый APK также публикуется в **Releases** репозитория.

## 🧪 Тесты

```bash
node zombie-town/test/smoke.js   # симуляция: рост города, бой, вспышка, сейв/лоад
```

Звук, музыка, вибрация, частицы, качество (лимит жителей/зомби), язык (RU/EN), сложность вспышки (мирная/лёгкая/нормальная/хардкор).
