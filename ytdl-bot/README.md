# ytdl-bot — ссылка на видео → файл в телеграм

Кидаешь боту ссылку на YouTube / TikTok / Instagram Reels / VK-видео — он
присылает видеофайл в максимальном доступном качестве.

## что умеет

- **youtube** — обычные видео, Shorts, youtu.be, music.youtube
- **tiktok** — включая короткие ссылки `vm.tiktok.com`
- **instagram reels** и **vk видео**
- **качество**: 1080p → 720p → 480p, лестница вниз по необходимости
- **лимит телеграма 50 МБ**: если исходник больше — пережимает ffmpeg'ом
  под лимит и честно пишет в подписи, что сжал
- **прогресс**: одно сообщение редактируется («качаю: 43%»), без спама
- защита от произвольных URL: домены из белого списка, `file://`,
  `localhost` и прочий мусор отклоняются

## запуск

бот живёт **на GitHub Actions сменами**: один job максимум 6 часов, поэтому
workflow поднимается по расписанию каждые 6 часов (`cron: 0 */6 * * *`)
и работает ~5.5 часа, затем выходит сам и перезапускается следующим cron'ом.
Раз в 6 часов бот недоступен несколько секунд — это нормальная плата за
бесплатный хостинг без сервера.

### 1. токен в секреты (обязательно)

токен **нельзя** держать в коде: репозиторий публичный, его выгребут
сканеры за минуты. положи его в секрет:

> Settings → Secrets and variables → Actions → **New repository secret**
> Name: `YTDL_BOT_TOKEN`
> Secret: токен от [@BotFather](https://t.me/BotFather)

### 2. запуск

> Actions → **ytdl-bot** → *Run workflow*

дальше он сам по расписанию.

### 3. если нужен бот 24/7

GitHub Actions — это «сменами», а не вечный хостинг. Для круглосуточной
работы положи этот же `bot.py` на любой VPS / fly.io / railway:

```bash
pip install -r requirements.txt && YTDL_BOT_TOKEN=... python bot.py
```

## проверить логику локально (без сети и токена)

```bash
python bot.py --selftest
```

проверяет белый список доменов, склейку дублей, обрезку трекинг-хвостов,
санити лимитов. гоняется в CI до запуска бота.

## файлы

| файл | что |
|---|---|
| `bot.py` | весь бот: long polling, скачивание, сжатие, отправка |
| `requirements.txt` | `yt-dlp`, `requests` |
| `.github/workflows/ytdl-bot.yml` | workflow: смены по расписанию |

## чего бот не умеет (честно)

- **приватные/закрытые видео** — yt-dlp их не достанет без cookies
- **файлы больше 50 МБ после сжатия** — это лимит Bot API, обходится только
  локальным Bot API server или клиентом Telegram Premium
- **плейлисты** — берётся первое видео (`noplaylist`)
- **ютуб иногда требует «подтвердите, что вы не робот»** с дата-центровых IP;
  тогда в логах будет `Sign in to confirm you're not a bot`, и видео может
  не скачаться. лечится cookies или прокси, это отдельная настройка
