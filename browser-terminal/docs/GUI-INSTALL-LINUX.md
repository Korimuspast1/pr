# Установка на Linux **без терминала** (только мышкой, через GUI)

Эта инструкция — если у вас есть доступ к компьютеру через браузер и файловый
менеджер (Nautilus/Dolphin/...), но **нет терминала**. Если нет вообще никакого
доступа к файловой системе машины — смотрите раздел «Только браузер» в основном README.md.

Важно: `install.bat` — это установщик для **Windows**, на Linux он не нужен.

## Шаг 0. Скачайте расширение на свой компьютер

Файлы, загруженные в чат/панель Files агента, лежат в сессии агента, а не у вас.
Скачайте архив расширения себе через браузер, например один из вариантов:

- кнопка ⬇ рядом с `browser-terminal.rar` в панели Files (потом распакуйте), или
- straight from GitHub: `https://github.com/Korimuspast1/pr/archive/refs/heads/arena/5cf1adac-pr.zip`
  (внутри будет папка `browser-terminal/`).

Распакуйте архив в удобную папку, например: `/home/ВАШ_ЮЗЕР/browser-terminal/`
(запомните точный путь — он понадобится ниже).

## Шаг 1. Загрузите расширение в Chrome

1. Откройте `chrome://extensions`
2. В правом верхнем углу включите **«Режим разработчика»**
3. Нажмите **«Загрузить распакованное расширение»** → выберите папку `browser-terminal`
4. На карточке расширения скопируйте **ID** (строка вида `abcdefghijklmnopqrstuvwxyzabcdef`)

## Шаг 2. Зарегистрируйте native-хост (вручную, без терминала)

1. Откройте файловый менеджер, нажмите **Ctrl+H** (показать скрытые файлы)
2. Зайдите в папку `.config` в вашей домашней директории (`/home/ВАШ_ЮЗЕР/.config`)
3. Если у вас **Google Chrome**: создайте папки `google-chrome/NativeMessagingHosts`
   (если `google-chrome` уже есть — просто зайдите в неё и создайте `NativeMessagingHosts`).
   Если у вас **Chromium**: то же самое, но папка называется `chromium`.
   Если **Brave**: `BraveSoftware/Brave-Browser`. Если **Edge**: `microsoft-edge`.
4. Откройте файл `browser-terminal/host/com.korimuspast.browserterminal.json`
   любым текстовым редактором и замените два плейсхолдера:
   - `__EXTENSION_ID__` → на ID из шага 1
   - `__HOST_ABS_PATH__` → на **полный** путь до скрипта, например:
     `/home/ВАШ_ЮЗЕР/browser-terminal/host/run-host.sh`
5. Сохраните этот файл **копией** в папку `NativeMessagingHosts` из шага 3 под именем
   `com.korimuspast.browserterminal.json`

Итоговый файл должен выглядеть примерно так:

```json
{
  "name": "com.korimuspast.browserterminal",
  "description": "Browser Terminal: локальное выполнение команд в системе (только для расширения-терминала)",
  "path": "/home/ВАШ_ЮЗЕР/browser-terminal/host/run-host.sh",
  "type": "stdio",
  "allowed_origins": ["chrome-extension://ВАШ_ID_РАСШИРЕНИЯ/"]
}
```

## Шаг 3. Сделайте хост исполняемым и проверьте python3

1. Правый клик по файлу `browser-terminal/host/run-host.sh` → **Свойства → Права** →
   поставьте галку **«Разрешить выполнение файла как программы»** (это аналог `chmod +x`).
2. Убедитесь, что в системе есть Python 3: откройте любое приложение-терминал, если оно есть,
   и введите `python3 --version`. Если терминала нет — обычно python3 уже установлен
   в большинстве дистрибутивов Linux; если при запуске расширения будет ошибка —
   установите пакет `python3` через «Менеджер программ» вашего дистрибутива.

## Шаг 4. Перезапустите Chrome и пользуйтесь

1. **Полностью закройте Chrome** (все окна, иначе хост не перечитается) и откройте заново.
2. Нажмите на иконку расширения 🖥 на панели инструментов Chrome (головоломка → Browser Terminal),
   либо откройте `chrome://extensions` и нажмите на расширении.
3. Откроется вкладка терминала. Проверьте: `ls -la`, `cd /tmp`, `pwd`, `python3 --version`.

Если в терминале пишет «нет соединения» — проверьте:
- ID расширения в JSON совпадает с ID на `chrome://extensions` (после перезагрузки расширения ID может смениться — тогда обновите JSON);
- путь в поле `path` указан абсолютно точно и файл существует;
- у `run-host.sh` стоит галка «исполняемый»;
- папка называется именно `NativeMessagingHosts` и лежит внутри папки профиля вашего браузера
  (`~/.config/google-chrome/NativeMessagingHosts` для Chrome).

## Быстрый самотест хоста (если вдруг появится терминал)

```bash
python3 browser-terminal/host/selftest.py
```
