# ⌨ Browser Terminal — терминал вашей системы прямо в браузере

Расширение для Chromium-браузеров (**Chrome, Chromium, Brave, Edge, Vivaldi, Opera, Thorium**;
в Firefox — см. ниже), которое открывает вкладку-терминал: вы печатаете команды
(`ls`, `cd`, `git status`, `python3`, `npm run build`, … — вообще любые), и они
**выполняются на вашем компьютере** как в обычном терминале. Текущая папка (`cd`)
и история команд сохраняются между вводом.

![схема работы](docs/schema.txt)

## ⚠️ Безопасность — прочитайте перед установкой

Это **настоящий терминал**: команды выполняются с правами вашего пользователя
и могут делать с системой всё, что можете вы (читать/писать файлы, ставить пакеты…).

Встроенные меры защиты:

- расширение **не** объявляет `externally_connectable` и **не** имеет `content_scripts` —
  **ни один сайт не может отправлять команды** в терминал, вводить команды можете только вы
  из вкладки расширения;
- native-хост регистрируется с `allowed_origins` = ID этого расширения — подключиться
  к нему может только оно;
- исходники полностью открыты и лежат рядом — можете проверить сами.

Устанавливайте расширение только из доверенного источника (этот репозиторий),
не давайте ID расширения третьим лицам и не публикуйте распакованное расширение публично.

## Как это работает

```
вкладка терминала (terminal.html, xterm.js)
        │  chrome.runtime.connectNative("com.korimuspast.browserterminal")
        ▼
host/run-host.sh → host/host.py   (процесс на вашем ПК, права вашего пользователя)
        │  каждая команда: $SHELL -c "<команда>" + маркер статуса/pwd
        ▼
ваш shell (bash/zsh/… или cmd.exe в Windows)
```

Протокол — стандартный Chrome Native Messaging (4 байта длины + JSON поверх stdio).
`cd` работает «по-настоящему»: после каждой команды хост узнаёт актуальный `pwd`
и помнит его для следующей команды.

## Установка

### 1. Загрузите расширение в браузер

1. Скачайте папку `browser-terminal` из этого репозитория.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Brave — `brave://extensions`).
3. Включите **«Режим разработчика»** (переключатель справа вверху).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку `browser-terminal`.
5. Скопируйте **ID** расширения (поле «ID» на карточке расширения, например `abcdefghijklmnop...`).

### 2. Зарегистрируйте локальный хост (скрипт делает всё сам)

**Linux / macOS:**

```bash
cd browser-terminal
./install.sh <ID_РАСШИРЕНИЯ>
```

Скрипт найдёт установленные профили Chrome/Chromium/Brave/Edge/Vivaldi/Opera/Thorium
и запишет манифест хоста в их папку `NativeMessagingHosts` с вашим ID расширения.

**Windows:**

```bat
cd browser-terminal
install.bat <ID_РАСШИРЕНИЯ>
```

Перед запуском убедитесь, что `python` есть в PATH (`python --version`).

**Firefox** (дополнительно): `./install.sh <ID_РАСШИРЕНИЯ> <внутренний UUID>` —
UUID берётся на `about:debugging` → «This Firefox» → у расширения поле «Внутренний UUID».

### 3. Пользуйтесь

Нажмите на иконку расширения в панели инструментов — откроется вкладка терминала.
Печатайте команды:

```bash
ls -la
cd ~/projects
pwd
git status
python3 --version
docker ps
```

Горячие клавиши: **↑/↓** — история команд, **Ctrl+C** — прервать выполняющуюся команду,
**Ctrl+L** — очистить экран, **Ctrl+U** — стереть строку, **Ctrl+W** — стереть слово,
**←/→/Home/End/Delete** — редактирование строки.

### 4. Проверьте хост без браузера (необязательно)

```bash
python3 host/selftest.py
```

Прогоняет протокол через `host.py` и проверяет echo/cd/pwd/коды ошибок/Ctrl+C.

## Ограничения

- Команды, читающие stdin интерактивно (`vim`, `htop`, `ssh` без ключей…), запустятся,
  но клавиатурный ввод в них не передаётся — завершайте их **Ctrl+C**.
- Вывод идёт порциями (streaming), цвета/ANSIsupported через xterm.js.

## Опционально: белый список команд

Если хотите жёстко ограничить набор разрешённых команд, задайте переменную окружения
**при запуске браузера** (или в `run-host.sh`):

```bash
export BROWSER_TERMINAL_WHITELIST=/etc/browser-terminal-allow.txt
```

Файл — по одному имени команды в строке (`ls`, `git`, `python3`, …; `#` — комментарий).
Все остальные команды будут отклонены с ошибкой.

## Удаление

- Расширение: `chrome://extensions` → карточка расширения → «Удалить».
- Хост: `./uninstall.sh` (Linux/macOS) или удалите ключи реестра
  `HKCU\Software\<Браузер>\NativeMessagingHosts\com.korimuspast.browserterminal` (Windows).

## Структура

```
browser-terminal/
├── manifest.json                 # MV3: только nativeMessaging+storage, НЕТ доступа для сайтов
├── background.js                 # клик по иконке открывает вкладку терминала
├── terminal.html / .css / .js    # UI терминала (xterm.js)
├── lib/                          # xterm.js + addon-fit (локально, без CDN — требование MV3 CSP)
├── icons/                        # иконки расширения
├── host/
│   ├── host.py                   # native messaging хост: выполняет команды в вашей системе
│   ├── com.korimuspast.browserterminal.json  # шаблон манифеста хоста (плейсхолдеры заполняет install)
│   ├── run-host.sh / run-host.bat            # обёртки-запускатели (абсолютный путь для браузера)
│   └── selftest.py               # smoke-тест хоста без браузера
├── install.sh / install.bat      # регистрация хоста во всех Chromium-браузерах
└── uninstall.sh
```
