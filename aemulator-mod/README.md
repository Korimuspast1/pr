# Доработки AEmulator

Патчи из этой папки накладываются на исходники https://github.com/uxazu/aemulator
при сборке workflow `.github/workflows/aemulator-apk.yml`.

## autofix.patch — автоисправление проблем

- **Перед запуском** приложение смотрит, сколько у телефона свободной оперативной памяти и места.
  Если памяти мало: выгружает фоновые приложения, чистит кэши, уменьшает память гостя под телефон,
  включает «режим малой памяти». Если мало места — чистит кэши и старые журналы.
- **Если система убила прошлую загрузку из-за нехватки памяти** (Android 11+: ApplicationExitInfo),
  следующая загрузка сразу идёт с меньшей памятью гостя.
- **Если система не запустилась** — журнал гостя разбирается и определяется причина:
  куча system_server мала (OutOfMemoryError) → больше памяти гостю; телефону не хватает памяти →
  режим малой памяти, экран 480×800, программная отрисовка; падает телефония → эмуляция радио выкл.;
  падает графика → hwui / GPU выкл.; причина не ясна → по очереди: вернуть свои настройки памяти,
  радио, GPU, 32-битный обход, hwui, JIT, режим малой памяти. До 8 попыток, шаги не повторяются.
  Причина и кусок журнала с падением пишутся в журнал и показываются на экране ошибки.
- Кнопка «Вернуть мои настройки и запустить» откатывает всё, что поменяло автоисправление.
- Бюджет памяти гостя больше не занижается «на всякий случай»: из него считается куча Java,
  и маленькая куча сама роняет system_server (zygote exited, code 137). Изменения версии 1 откатываются.
- **Во время работы**, когда телефону не хватает памяти (onTrimMemory), гость сам выгружает
  свои фоновые приложения.
- Выключается в Настройки → «Решение проблем» → «Исправлять проблемы автоматически».
